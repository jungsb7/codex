# Planet Observatory v0.77

[시뮬레이터 실행](https://jungsb7.github.io/codex/)

지형 탐색에서 **통합 지역 지도 열기**를 선택하세요. 지형·물·농지·식량과 생활·조사 범위를 같은 지도에서 비교합니다. 지역을 선택하고 작물, 관개 조건, 수송 거리, 4년차 사건과 계절을 바꿀 수 있습니다.

기존 25개 계산은 지도 안의 계산 이력에 위치·범위로 연결했습니다. 저장된 상세 격자가 있는 결과는 지도 색으로, 지역 단위 결과는 표식과 시계열로 표시합니다. 좌표가 없는 도로·마을은 임의로 만들지 않습니다. 저장된 기준 세계와 현재 세계 재계산은 별도로 선택합니다.

## 호스팅

GitHub Pages: main / (root). 서버와 API 키가 필요하지 않습니다. 최신 Chrome, Edge, Firefox, Safari에서 실행합니다.

v0.76의 불변 압축 파일을 재사용하고 v0.77 변경분을 적용합니다. 기본 파일과 재구성된 전체 HTML의 SHA-256을 모두 검사한 뒤 실행하므로 독립 HTML 배포본과 정확히 같습니다. 파일 일부를 수동 변경하면 무결성 검사가 실패합니다.

배포본 SHA-256: `02abbff39b732a09a55dc02f7fc587da7cdac7854cfa70c4e4c80877acca8de2`

모든 농지·생산·인구 값은 해당 계산의 가정에 따른 조건부 결과입니다. 현재 배치에는 농번기 노동력 부족이 남아 있습니다.
