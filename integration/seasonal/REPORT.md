# 왕국 계절 비축·제국 수송 비교 결과

기존 전 권역 통합 다음 단계로 왕국 5개국의 48기간 식량·비축 비교와 제국 수송 자원 민감도를 구현했다. 세계·인구·배정 농지와 원본 앱을 바꾸지 않았다. 왕국 계절값은 추가 가정에 의한 미채택 비교이며, 원래 기준안의 미확인 값도 지도에서 확인할 수 있다.

## 핵심 결과

연간 생산이 수요보다 많아도 첫 수확 이전 부족은 남는다. 초기 식용 비축을 180일분으로 두면 첫해 남서왕국 D는 8기에 27,200.1 t, 해상공화국 E는 7·8기에 110,100.2 t 부족하다. 기말 재고가 남아도 이미 지나간 계절의 부족을 소급해 상쇄하지 않는다. 아래 부족량은 열량·단백질 중 더 큰 부족을 곡물로 환산한 값이다.

| 왕국 비교안 | 첫해 부족 t | 4년 차 부족 t | 4년간 출발 거래 수 |
|---|---:|---:|---:|
| 왕국 계절 · 초기 비축 0일 | 3,631,857.8 | 0.0 | 0 |
| 왕국 계절 · 초기 비축 90일 | 1,409,721.2 | 0.0 | 0 |
| 왕국 계절 · 초기 비축 180일 | 137,300.4 | 0.0 | 0 |

| 왕국 계절 · 180일 · 가정 교역 | 137,300.4 | 0.0 | 11 |

4년 차의 부족 0은 앞선 평년 3년간 재고를 쌓고 국내 공동 창고에 접근한다는 조건에 의존한다. 4년 반복 결과를 장기 안정성으로 해석하지 않는다. 저장 손실과 수확 감소는 반영하지만 창고 파괴·국내 분배 장애·영양 부족의 노동 영향·가축 무리 회복은 모의하지 않는다.

교역안은 1·2년 차에만 11건 출발한다. 수출국 180일 비축 유지, 직결 후보 경로, 이동 지연과 처리 상한 때문에 첫해 D/E 부족을 줄이지 못했다. 3년 차 이후 출발이 없으므로 이번 설정에서 4년 차 교역 중단 효과는 식별되지 않는다. 교역 중단에 안전하다는 결론은 아니다. 별도 긴 이동시간 시험에서는 중단 후에도 기존 화물이 도착하는 것을 검증했다.

## 첫해 초기 비축 임계값

평년·교역 없음·국내 공동창고 접근·균등 신선식품 공급·별도 종자 은행 조건에서 첫해 부족을 없애는 초기 식용 곡물량을 일수로 표시했다. 실제 비축량이나 정책 권고량이 아니다. 0~365일 범위 이분법 20회, 부족 허용 오차 0.001 t이며 표는 반올림이다. 보수적으로 정수 일수를 사용할 때는 올림해야 한다.

| 권역 | 초기 곡물 환산 일수 |
|---|---:|
| A | 120.193 |
| B | 86.601 |
| C | 163.411 |
| D | 185.905 |
| E | 235.553 |

## 제국 수송 민감도

기존 두 육로에 각각 수레 1,000대, 전용 역축 4,000 LU, 초기 조사료 50,000 t를 둔 예제를 기준으로 비교했다. 증차·역축·조사료는 확보를 가정한 입력이지 실제 보유 자원이 아니다. 늘어난 역축은 기존 계획 가축 중에서 배정하고 초지를 다시 나누며 공유 노동·사료·식용 곡물 차감을 재계산한다. 농지·물 공급·기초 식용 비축·주민·노선은 동일하다.

| 비교 | 4년 차 곡물 도착 t | 4년 차 부족 t |
|---|---:|---:|
| 기존 수송 가정 | 1,900.0 | 2,262,208.4 |
| 기존 수송 가정 · 4년 차 흉작 | 0.0 | 2,758,854.1 |
| 수레만 2배 | 1,900.0 | 2,262,195.5 |
| 수레만 2배 · 4년 차 흉작 | 0.0 | 2,758,854.1 |
| 수레·역축·초기 조사료 2배 | 3,800.0 | 2,260,360.4 |
| 수레·역축·초기 조사료 2배 · 4년 차 흉작 | 0.0 | 2,758,854.1 |

수레만 두 배인 경우 총 도착량은 그대로이며 분지·해안 배분이 달라져 부족이 약 12.8 t 줄었다. 역축·초기 조사료까지 두 배인 경우 도착량은 1,900→3,800 t로 늘지만 부족 감소는 약 1,848 t(0.082%)다. 하류 기말 곡물은 기준안 약 1,421만 t인 반면 다른 권역에 부족이 남는다. 이 규모의 증차만으로 전국 부족을 해소할 수 없다. 변경 연결 노선도 여전히 없다.

제국 흉작 조건에는 기존 정책인 4년 차 신규 출발 중단이 포함된다. 세 자원안 모두 해당 연도 도착량이 0이므로 흉작 때 증차 효과가 없다는 보편적 결론을 내릴 수 없다. 지도에는 기존 제국 수송 가정을 유지하고, 민감도는 별도 표로 표시했다.

## 근거와 추가 가정

1. 원본 `food-comparison/comparison.json`의 국가별 배정·인구·수량·종자·가축·어획 한도를 유지했다. 기존 파종 면적을 기후 후보지 면적 비중에 균등 배정하며, 후보 격자의 4기간 작기 마지막 기간에 수확한다고 가정했다. 콩은 곡물 작기를 공유하는 미검증 가정이다. 후보지는 실제 경작 필지나 관측 수확 기록이 아니다.
2. 12기간은 공전각 0°, 30°… 기준 각 365/12일이다. 그레고리력 월이 아니며 기간 내부 수확·배급 순서의 일별 차이는 모의하지 않는다. 입력에는 연말을 넘는 작기가 없고, 그런 입력은 선행 작물 근거 없이 자동 계산하지 않도록 거부한다.
3. 초기 식용 곡물은 0·90·180일분으로 비교한다. 종자는 기존 파종 면적의 연간 필요량을 별도 은행에 둔 가정이며 식용 생산에 더하지 않는다. 파종·종자 수확·이월을 따로 보존한다.
4. 기존 연간 작물 저장 공제 10%를 복원한 뒤 실제 기초 재고에 기간당 `1−0.9^(1/12)` 손실을 적용한다. 같은 작물 생산량에서 손실 시점만 바꾸며 공제를 중복하지 않는다. 신선식품은 기존 연간 사료 제약 생산량을 12기간 균등 공급하고 남은 양은 폐기한다. 접근 불가 비교도 제공했다.
5. 왕국 내부는 접근 가능한 공동 창고라는 가정이다. 국내 집하·마을 배급·냉장 능력·계절 노동·실제 창고 용량은 미확인이다. 연간 사료 부족 값은 보존하되 기간별 사료 부족을 임의로 12등분하지 않았다.
6. 원본 앱에서 AB·BC·BD 육로, CE·DE 해로와 항구 연결 후보를 추출했다. 육로 계절 이동시간은 앱 값을, 해로 속도 100 km/일과 취급 1일은 기존 예제값을 사용한다. 역방향 대칭 이동은 가정이다. 도착은 최소 다음 기간이고 장거리 지연을 반영한다.
7. 교역 전체 연간 상한 100,000 t와 국가별 상한·손실 10%는 기존 가정이다. 전체 상한을 12등분한 출발 처리량과 국가 공동 창고 간 직결 거래를 가정한다. 연간 시장 상한은 수레·선단·왕복·인력·사료로 검증한 실제 운송 능력이 아니다. 외부나 왕국–제국 구제 수입을 추가하지 않았다.
8. 왕국 흉작은 4년 차 강수작물 계수 ×0.6, 목초 ×0.5, 어획 ×0.75다. 새 날씨나 토질 +25%를 생성·적용하지 않았다. 실제 초기 비축·수확 일정·운송 능력과 안정 부양 인구는 `null`로 남는다.

## 검증과 보존

- 신규 17개 검증: 결정론적 재현, 원본 연간 생산 일치, 식량·종자·수송 보존/이월, 초기 재고 분리, 흉작 시점, 경로·상한·지연·중단·신선 접근, 임계값 양쪽 경계, 원본 기준안 보존과 공동 합계.
- 기존 왕국·통합식량 모델 30개 검증 통과. 이전 통합 단계의 총 251개 검증 기록과 구분하며 이번에 모두 재실행했다고 주장하지 않는다.
- 브라우저 12개 검증: CLI와 모든 데이터 일치, 10개 비교안·9권역·48기간 선택, 원본 미확인, 지도 클릭·지표, 거래, 표·링크, JSON 다운로드, 390px 화면, 오류 없음.
- 원본 앱·AI·설정·이전 원장 등 integration 밖 1,663개 파일 SHA-256 보존. 이전 통합 계산·지도·보고서도 그대로 두고 상태·진행·진입 문서만 후속 완료로 갱신한다.
- 실제 확인 결과: `validation/final-checks.json`, `validation/tests.txt`, `validation/existing-tests.txt`, `validation/browser-checks.json`.

## 다음 근거 확보 우선순위

D/E의 실제 초기 식용 비축·종자 확보·수확 일정·국내 집하/배급/저장 자료를 우선한다. 모형 비교를 더 한다면 수확 시점 변화와 지속적인 교역 의존 조건을 명시해서 시험한다. 제국은 증차 반복보다 기존 노선의 왕복 점유·역축/사료·부족 권역의 현지 접근과 연결을 먼저 진단한다. 추가 시설·농지·실제 자원 확보는 자동 채택하지 않는다.
