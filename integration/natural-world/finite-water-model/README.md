# 침투·유한 저장·출구 작동 후보

후속36은 기존 원본35% 얕은 저장 분배를 반복하는 대신, **유한 토양·대수층, 제한된 침투, 지하수 복귀, 수위에 따른 유한 방류**를 함께 계산한다. 원본 설정을 수정하지 않는 별도 설계 후보다. [화면](index.html) · [결과](REPORT.md).

## 범위와 출처

- D186192까지 닫힌 상류57경계·11,355원본 격자·2,637구간. 이전 후속35의 원본 강수·기온·초기 눈/혼합 저장과 기둥·웅덩이·진입점을 읽는다. 다른20,385구간에 이 모델을 적용했다고 표시하지 않는다.
- 입력은 `../basin-water-budget/source.cjs`가 기존18개 조각의 SHA-256을 검증해 읽는다. 원본 계측10.2MB를 복제하거나 재게시하지 않는다. 모델·입력 해시는 `output/summary.json`에 있다.
- 원본 수계/마스크/기후/경제/구지도 불변. D298591 연결망과 기존108보류·14중단, 종료9곳/D193196/D126467/D147845/D144758은 재개하지 않는다.
- 원본12위상은 지구 달력 월이 아니다. 365일/년은 기존 계산 시간 단위 가정이며 각 위상을1/12년으로 균등 배분한다. 원본 지역 위상을 그대로 반복한다.

## 물 이동과 보존

격자마다 눈, 토양, 지하수를 따로 저장한다. 기존 초기 혼합 저장은 토양 용량까지 채우고, 나머지를 지하수 용량까지 채운다. 그래도 남으면 원본 배정 웅덩이에 넣는다. 이 초기 분할은 새 가정이며 초기 물 총량은 보존한다.

한 소단계에서 지하수는 `G(1-exp(-dt/τg))`만큼 원본 웅덩이로 돌아온다. 토양은 `S(1-exp(-dt/τs))`와 대수층 여유 중 작은 양만 지하수로 보낸다. 음수/용량 초과로 물을 삭제하지 않는다. 젖지 않은 격자는 액체 강수·융설에서 증발산을 뺀 다음 `min(남은 물,K dt,토양 여유)`가 침투하고 나머지가 지표 유출한다. 젖은 격자의 액체 강수·융설은 직접 수면으로 간다. 젖은 토양도 기존 저장의 배수·지하수 복귀는 계속한다.

영하 강수는 눈, 양의 기온에서 기존540mm/(°C·년) 융설 상한을 사용한다. 잠재 증발산은 기존 `max(T+5,0)*24 mm/년` 관계를 계승하되 혼합 저장 대신 토양에서 인출한다. 눈/에너지/증발산 모델을 새로 완성한 것은 아니다. 하상 침투와 외부 지하수 손실은 이 후보에서0이며 모든 지하수 복귀는 지역 내부다.

표면의 원본 웅덩이 분할·안장 연결은 재사용한다. 문턱 위에는 기존 기둥 면적을5m까지 수직 연장한 **가상 저장 공간**이 있다. 원본 지형에 벽을 추가하거나 실제 침수 지도를 만든 것은 아니다. 실제 주변 확장/다른 출구/범람은 이 후보로 판단할 수 없다.

출구는 다음 **설계된 단방향 수위 함수**다. 관측 보정된 잠긴 월류 공식이라고 주장하지 않는다.

`Q = C W max(max(zu-zc,0)^1.5 - max(zd-zc,0)^1.5, 0)`

`zu`는 상류 저장 수위, `zc`는 원본 문턱, `zd`는 이전 소단계의 하류 진입 웅덩이 수위다. 바다 출구는 자유 방류다. 하류의 수면이 없으면 문턱 수위를 사용한다. 역류·경로별 수리 손실·실제 유하 시간은 지원하지 않는다. 따라서 이 규칙은 세계 채택 전 단방향 후보이지 일반적인 역수위 해석기가 아니다.

유입과 출구 방류를 후진 오일러 저장 방정식으로 풀어, 수면이 줄면 방류도 줄도록 한다. 상한 안에 해가 없으면 상한 수위의 방류만 하고 남는 물을 `unresolvedM3`에 따로 기록한다. 그런 조건은 `domain-exceeded`로 남으며 물리적으로 처리 완료라고 표시하지 않는다. 후속 계산은 잘린 후보의 진단값일 뿐이다.

각 소단계 시작의 하류 수위를 모두 먼저 읽고, 모든 경계의 계산 후 방류를 수신 경계의 `transitM3`에 넣는다. 다음 소단계에 원본 진입점으로 공급한다. 순회 순서와 무관하며 내부 송수신은 정확히 한 번이다. 이 한 소단계 지연은 수치 계산 방식이지 실제 이동 시간 가정이 아니다. 종료 시 전달 중인 물도 재고에 포함한다.

연간·전체 보존은 독립적인 시작/종료 재고로 검사한다:

`초기 재고 + 강수 + 수신 = 육지 증발산 + 수면 증발 + 방류 + 미처리 + 종료 재고`

57경계 전체에서는 내부 송수신이 상쇄된다. 전체 네트워크 표시에서는57경계의 기존 집계 입력/손실/재고 및 원본 해양 방류를 빼고 새 장부를 더한다. 다른 경계의 기존 미배분량은 유지한다. 전체 네트워크 장부는 혼합 해상도이며 전체 물리 완료율이 아니다.

## 완료 조건의 변화

토양/지하수 저장 한계, 침투와 복귀, 제한된 출구 방류는 이제 구체적인 작동 후보가 있다. 물리 정확도나 세계 설정 채택을 완료한 것은 아니다. 다른20,385구간의 입력 적용, 하상 침투·외부 지하수 교환, 실제 침수/대체 출구, 일반 역류·채널 수리, 고온·극지/빙설 열수지가 남는다. 이 항목을 작은 연결 증가나 검사 횟수로 대체하지 않는다.

`chain.releasedM3`는 각 경계 방류 합으로 내부 이동도 포함한다. 해양 도착은 `chain.oceanDeliveryM3`만 사용한다. `internalSentM3`와`receivedM3`는 같은 물이며 외부 유입에 합산하지 않는다. `transitM3`는 수신 경계의 재고이고, 다음 단계 공급 시 다시 수신량으로 세지 않는다.

최초30단계/위상과60단계 비교에서100년 해양 전달 차이가1.2552%로 사전에 정한1% 기준을 넘었다. 따라서 공개 기본값을60단계로 올리고 기준 후보 전체57경계·100년을120단계와 다시 비교한다. 두 민감도 조건은60단계로 계산하되 각각의 별도 간격 검증은 수행하지 않는다. 출구 폭은 최대 약38.5km에 이르는 유효 설계 폭이며 실제 강폭 추정치가 아니다.
