# 언제 완료되는가

지금까지의 작업은 원본 자료 복원과 조건부 계산 연결에 집중했다. 이것만 반복하면 실제 미정 항목은 끝나지 않는다. **‘계산 가능’, ‘선택한 가정 아래 처리 완료’, ‘세계 설정으로 채택 완료’를 구분해야 한다.** 검사 수나 배포 횟수는 완료 기준이 아니다.

이것은 창작 세계이므로 지구의 관측자료를 기다려야만 끝낼 수 있는 문제가 아니다. 없는 물리 입력은 출처가 있는 원본 값과 구분해 모델 가정으로 정하고, 검증한 후 세계 설정 채택 여부를 판단할 수 있다. 반대로 새 가정을 전혀 허용하지 않으면 원본에 없는 실제 침투·하도·빙설 값은 끝까지 미정으로 남는다. 기존 미정값을 임의로 확정값으로 바꾸지 않는다.

## 이번 작업의 범위

| 상태 | 구간 수 | 의미 |
|---|---:|---|
| 원본 수분 장부까지 연결 | 2,827 | 기존190 + 이번2,637. 각 경계의 원본 기후·눈·얕은 저장과 수면 전환 계산 |
| 집계 모형까지만 연결 | 17,428 | 자체 유입·집계 용량·명시적 손실·초과 전달, 세부 수분 장부 미연결 |
| 자체 처리 보류 | 2,767 | 방법 공백 또는 기존 보류. 미배분량 보존만 수행 |
| 전체 | 23,022 | 위 세 범주는 서로 겹치지 않음 |

이는 세계 설정 채택률이나 물리 정확도가 아니다. 원본 수분 장부 연결2,827구간에도 실제 침투·출구·역수위가 남는다. 실제 물리 해결/채택 완료는0이며 `actual` 값은null이다.

## 작업을 끝내기 위한 판정 조건

1. **처리 경로:** 전체23,022구간의 끝점에 저장·손실·다음 경계/해양 전달 또는 명시적 영구 폐쇄 처리가 정해져야 한다. 계산 실패를 물량0으로 숨기거나 보류량을 자동 방류하지 않는다.
2. **저장과 침투:** 적용 가능한 토양/얕은 지하수 저장 한계, 침투와 되돌아오는 양, 외부 손실을 정하고 단위·범위·출처를 기록한다. 원본35%분배를 실제 침투율로 바꾸는 것은 이 조건을 충족하지 않는다.
3. **출구와 수위:** 필요한 출구 형상/방류 관계, 하류 수위 또는 역수위 처리 규칙을 정한다. 현재의 같은 기간 즉시 용량 초과 전달은 이 조건을 충족하지 않는다.
4. **기후 예외:** 고온 증발산과 극지 눈·융설·얼음 처리에 지원되는 계산을 적용한다. 연간 눈 증가가 단순 누적 오류인지 선택한 정상적인 빙설 저장인지 구분한다.
5. **전역 검증과 채택:** 모든 외부 유입·손실·해양 도착·눈/토양/지하수/수면 재고가 보존되고, 시간 간격 변화에도 안정적이어야 한다. 가정의 민감도와 적용 한계를 공개한 다음 세계 설정으로의 채택 여부를 기록한다.

‘완료’는 이 조건들을 충족한 구간에만 집계한다. 새 가정이 포함된 계산을 현실 관측값이나 원본의 확정 설정으로 표시하지 않는다. 원본과 설계 후보는 각각 남긴다.

## 다음 작업의 우선순위

- 우선 **침투·저장·출구의 최소 작동 모델과 적용 범위**를 명시해 검증한다. 작은 유역의 연결 숫자만 늘리는 작업을 반복하지 않는다.
- 그 모델을 전체 경계에 적용할 수 있도록 입력을 일괄 수집하고, 고온·극지·수위 결합 예외를 처리한다. 종료된9곳과 기존 특정 보류 대상은 사용자 지시 없이 재개하지 않는다.
- 마지막으로 위 판정 조건에 따라 구간별 완료/미완료와 사유를 집계하고 지도·AI 조회에 동일하게 반영한다.

완료 날짜나 ‘몇 번 더 다음이라고 하면 끝난다’는 횟수는 아직 산정할 근거가 없다. 특히 모델 가정의 채택 기준이 미정이다. 다음 인계에서는 어떤 판정 조건을 충족했는지와 남은 공백을 보고하며, 조건부 연결 수 증가를 실제 해결 완료로 대신 보고하지 않는다.

실제 소하천·계곡 세부 경로, 숲/습지 경계, 강폭·침수·적설두께·결빙 지도는 별도의 공간 해상도와 모델 입력이 필요한 산출물이다. 이번 물량 연결만으로 완료됐다고 표시하지 않는다.
