D186192로 이어지는57경계·2,637구간을 추가한다. 기존 D298591 연결망3경계·190구간을 함께 실행해 **60경계·12,045격자·2,827구간**의 원본 수분 장부를 연결한다. 두 연결망은 원본 집수 영역이 겹치지 않는다. 나머지889계산 경계와235보류 경계는 이전 집계/미배분 모형을 유지한다.

## 재사용과 원본 검증

후속34 `water-budget-chain/core.cjs`, 후속33 `water-budget-link/surface.cjs`, 후속24 원본 육지 `step`과 웅덩이 엔진을 수정 없이 재사용한다. 원본 입력을 다른 유역에 복사하지 않는다. 신규57경계의 원본 집수격자11,355개를 더해 총12,045격자×12위상=144,540행을 직접 계측했다.

고정 아카이브 v0.107의 메모리 사본에 읽기 전용 계측을 붙인다. 전268,857격자 원본 유출의 비트 해시·전역 물수지·세계/기하 해시를 대조한다. 다른 북부 산술 분기를 만나면 계산을 거부한다. 기존690격자의 원본 자료와 기존3경계의100년 결과를 그대로 재현해야 한다.

원본 terminal/canonical/receiver/entry에서 각 경계의 집수 영역과 진입점을 추적한다. 총2,186용량 기둥과105국지 웅덩이를 사용한다. 큰 유역의 용량 합산 순서에 따른 부동소수점 차이는 `max(0.01m³,128×Number.EPSILON×용량)` 이내인지 확인한다. 문턱/원본 지형/호수/해양 마스크/receiver를 변경하지 않는다.

## 계산 의미

각 경계가 자신의 원시12위상 강수·기온·초기 눈·혼합 얕은 저장을 사용한다. 상류부터 계산한 기간별 초과량을 원본 진입점으로 보내며, 같은 기간30하위단계에 균등 배분한다. 새 유역56개와 이전2개, 총58개 내부 송수신 연결을 추적한다. 해양으로 직접 나가는 경계는D186192와D298591이다.

```
지역 강수 + 상류 수신
= 육지 증발산 + 수면 증발 + 외부 지하수 손실 + 문턱 초과 전달
  + Δ눈 + Δ얕은 저장 + Δ수면 재고
```

전체 장부에서는 내부 송신/수신을 상쇄한다. 기존60경계의 자체 유입·손실·재고를 제거하고 새 장부로 교체한다. 해양 입출력에는 해양과 직접 연결된 두 경계만 반영한다. 하류 경로에는 교체 전후 차이를 한 번씩 반영한다. 음의 차이는 기존 예상 전달량 감소이며 역류가 아니다. 보류235경계의 미배분량은 실제 저장량이 아니며 그대로 보존한다.

공개3조건은100년·기간당30단계·초기 수면0, 수면 증발0.5/1/2m/년·외부 손실0/0.25m/년이다. 수면으로 전환된 칸은 육지 유출/증발산 대신 강수·융설을 한 번 넣는다. 원본35%얕은 저장 분배는 내부 이동이며 실제 침투율이 아니다. 외부 지하수 순손실도 측정된 침투가 아니다.

기간 내 균등 전달·유하 시간0·하도 손실0·역수위 없음은 가정이다.12위상은 지구 달력 월이 아니다. 다른 경계의 인접 위상 평균 집계 유입과 이번60경계의 원시 기후를 합친 전역 장부는 혼합 계산 영역이며 전체 행성 강수가 아니다.

실제 침투·출구 통수능·역수위·수면 열수지·적설두께·얼음은 확정하지 않는다. 기존108보류·14중단·지속 적설 문제와 종료대상을 유지한다. `actual:null`, `automaticAdoption:false`, `sourceGraphChanged:false`. **계산 연결은 세계 설정 채택 완료가 아니다.** 완료 판정은 별도 [기준](COMPLETION.md)을 따른다.

`inputs/flux-00.bin`부터18조각은 하나의 계측gzip을 바이트 단위로 나눈 것이다. `source.cjs`는 각 조각 및 합친gzip의 길이/SHA-256을 확인해 메모리에서 해제한다. 축약·반올림·표본화가 아니다. 이후 재현에는 전체 아카이브가 필요 없다.
