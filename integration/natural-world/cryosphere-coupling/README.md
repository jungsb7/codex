# 빙설·동토와 같은 물 장부의 연결 — 후속51

기준 main `6f2826af3c490881fef9e6c23f986f97f000507b`. [고정 가정](assumptions.json)의 범위와 계수로만 계산한다. 원본·채택판·후속50의 결과를 보존하는 별도 가정 시나리오다. 고정된 2년 실험과 비교·검증을 완료했다. 수치 결과와 한계는 [REPORT](REPORT.md)에 기록한다.

168,576개 대상 육지의 눈·토양·지하수·이동 저장과19,990개 저류칸의101년 말 수량을 이어받는다. 새 빙하/수면 얼음은0에서 시작한다. 초기 토양 온도는 각 원본 기후의 연평균이다. 동일한12기간 기후를2년 반복하며 기간당240단계,120단계 비교,240단계 빙하 이동0대조를 순차 실행한다.2년 후 연간 재고 변화율을 보고하며 평형에 도달할 때까지 계산을 늘리지 않는다.

## 질량과 법칙

- 기존 눈 저장에서1,000mm SWE 초과분을10년 시간상수의 지수 압밀로 얼음에 옮긴다. 기존 강설/융설·승화 규칙은 유지한다. 눈이 덮인 시간에는 먼저 눈에 융해량을 쓰고, 노출된 시간 비율에만8mm/°C/day의 얼음 융해를 적용한다. 융수는 기존 습윤/건조 땅의 침투·유출 계산에 한 번만 더한다.
- 빙하는 원본 평균 지형+얼음 두께의 경사로 흐른다. Glen지수3,율상수2.4e-24Pa^-3s^-1,밀도917kg/m³의 얕은 변형 유속 `2A/5 (ρg)^3 H^4 |slope|^3`를4방향 공유 변에 적용한다. 출발 칸의 얼음 두께를 사용하는 명시적 유한체적 이동이며, 원래 집수권을 넘으면 받음/보냄 장부에도 기록한다. 대상 밖 육지·호수·바다 경계는 무유속이다. 한 단계의 총 방출은 출발 얼음의20%로 제한하고 제한 횟수와 제한 전 최대 유속을 공개한다. 큰 제한 횟수는 시간 정확성의 보장이 아니다.
- 수면 얼음은 물 당량m³로 보관한다. 음의 온도에서2mm/°C/day,양의 온도에서4mm/°C/day에 젖은 면적을 곱해 액체와 교환하며 가용 질량을 넘지 않는다. 부유 얼음의 물 당량 변위로 저장곡선에 들어간다. 액체만 방류·침투·증발할 수 있다. 완전히 언 저장소의 환산 높이를 실제 액체 수면으로 부르지 않는다. 얼음 접지·자유수면 위 높이를 별도로 풀지 않는 유효 수두 가정이다. 얼음 비율에 따라 연결의 월류계수를 최저5%까지 줄이는 가정이다. 원래 연결·폭·출구는 유지한다. 얼음 변위 때문에 액체0에서도 수두가 남을 수 있으므로,월류 수요가 가용 액체를 넘는 경우 출발 액체만 모두 이동시키는 고갈 경계를 적용한다. 이때 미충족 수요와 제한 횟수를 별도로 기록하며,이를 무제약 월류 방정식의 잔차 통과로 바꾸지 않는다.
- 토양 온도는2년 시간상수로 기온을 따른다. `clamp(-Tsoil/5,0,1)`을 동토의 **제한 지수**로 사용해 침투·함양·지하수 복귀율을 최저5%까지 줄인다. 실제 토양 공극 얼음의 체적 비율이나 잠열을 푼 값이 아니다. 수면 결빙은 별도의 실제 모형 질량 저장이다.

계산 장부의 첫 재고는 눈+빙하 얼음,마지막 재고는 지표 액체+수면 얼음이다. 빙하 이동을 포함한 집수권 간 교환은 양쪽 장부에 같은 양으로 기록한다. 압밀·융해·동결은 외부 입력으로 더하지 않는다. 별도 얼음 장부로 원본 칸마다 `초기+압밀+유입−융해−유출=끝`을 확인한다.

수면 온도는 해당 저류칸에 속한 원본 격자의 면적 가중 기온이다. 대상 육지는 기존 수문 입력의 정확한 기온을 쓰고,배경/호수는 기존 계절 자료의float32 기온을 사용한다. 배경 유출과 원래 호수 강수/증발 입력은 보존한다. 원본 호수 마스크에 가상의 최소 물량을 추가하지 않는다.

## 검증과 재현

```sh
node integration/natural-world/cryosphere-coupling/compile.cjs /tmp/node-v24.19.0/include/node
node --test --test-isolation=none integration/natural-world/cryosphere-coupling/test-engine.cjs
node integration/natural-world/cryosphere-coupling/run.cjs
```

`run.cjs`는 전체 후속50 출력 일치 대조→120단계→240단계→이동0대조를 하나씩 실행한다. 새 입력이 없을 때 이전 수치 경로를 보존한다.16GiB에서 전체 실행을 겹쳐 시작하지 않는다. 캐시는 저장소 밖 `/workspace/cryosphere-cache-51`,실행기는 `/tmp/cryosphere-coupling.node`다. 실행 잠금이 있으면 현재 프로세스를 먼저 확인한다.

자료는 기간 말 상태와 기간 내 끝점 극값을 제공한다. 이번 추가 단계는 수위 전 시간 이력을 중복 저장하지 않으며,후속50의 공개 이력은 그대로 보존한다. 입력·엔진 해시가 같은 완료 캐시만 재사용한다.

## 범위의 한계

정한2년 실험은 빙하 평형이나 실제 얼음 두께 검증이 아니다. 대기 열수지를 닫지 않으며,degree-day계수는 외부 열 경계의 단순화다. 토양의 동결 잠열·기저 활주·빙산 분리·해빙·미세 균열을 풀지 않는다. 육지 빙하가 채택 지형이나 원래 물길을 덮어쓰지 않으며,얼음의 하상 변형/침식은 이번 단계의 법칙이 아니다. 후속50의 시간4.046m·공간14.574m 수위 민감도는 그대로 입력 한계로 남는다. 이 결과를 정설의 관측 검증이나 모든 세부 구현 완료로 표현하지 않는다.

## 지도와 AI 조회

지도와 CLI는 동일한 `core.js`를 쓴다. 생성된 manifest의 길이/SHA-256을 확인한 뒤 원본float64를 읽는다.9MB 넘는 gzip은 순서가 정해진 조각으로 나누되 합친 압축 바이트의 해시까지 검사한다.

```sh
node integration/natural-world/cryosphere-coupling/build.cjs
node integration/natural-world/cryosphere-coupling/query.cjs cell 268458 7 103
node integration/natural-world/cryosphere-coupling/query.cjs budget world 7 103
node integration/natural-world/cryosphere-coupling/query.cjs exchange 0 7 103
node integration/natural-world/cryosphere-coupling/query.cjs annual 268458 1 103
node --test --test-isolation=none integration/natural-world/cryosphere-coupling/test-data.cjs
node integration/natural-world/cryosphere-coupling/browser-check.cjs
```

`cell`의 `source`는 대상 육지의 눈/빙하/동토 계산이고 `surface`는 원래 저류칸의 액체/얼음 계산이다. 배경 육지·원본 호수에는 `source:null`,바다에는둘다null이다. 수치0과대상밖null을구분한다. `waterEquivalentStorageLevelM`은질량변위를포함한모형높이이며,모두 얼었거나 선택 칸에 물이 없으면 `liquidSurfaceLevelM:null`로 국지 액체 수면 없음을 표시한다. 저류칸 공통 높이는 선택한 지표 아래일 수도 있다.

`exchange`는기존저류칸연결의액체이동이다. 빙하의칸별받음/보냄은source장부에서따로확인한다. 23,022개개별물길의유량을저류칸유량에서복사하지않으며그연결은다음52단계다. 103년말눈/토양/지하수/이동·빙하·토양온도·지표액체/얼음은공개final-state에보존해다음계산이이어받는다.

공개 결과는 145,535,948바이트다. 관련 비교 배열을 기준 배열과 바이트 단위 XOR한 뒤 바이트 재배열/gzip으로 압축하여 최초 239,186,761바이트 패키지를 줄였다. float64 값을 반올림하거나 지형을 간소화하지 않았다. 모든 기간 배열과 최종 상태를 계산 원본과 비트 단위로 대조했다. `codec.js`는 XOR 중간 비트를 부동소수 값으로 해석하지 않는다.
