## 강폭

사다리꼴 개수로에서 밑폭 `b=8d`, 양안 경사 `z=1.5`를 가정한다. 단면적 `A=(8+1.5)d²`, 윤변 `P=(8+2√(1+1.5²))d`, 동수반경 `R=A/P`다. Manning 식 `Q=A R^(2/3) √S / n`을 깊이d에 대해 해석적으로 풀고, 수면 폭은 `(8+2×1.5)d`로 계산한다. 기준 거칠기n=.035, 비교 범위 .025/.05를 제공한다.

에너지 경사S는 원본 시작점→다음 연결 지점의 고도차/구간 길이다. 해양 수신자는0m를 기준으로 한다. 역경사·평탄·너무 낮은 경사는1e-5의 비교 가정으로 대체하고 `minimumSlopeAssumed`로 표시한다. 실제 에너지 경사와 바닥 단면은 관측되지 않았다. 유량0이면 개수로 폭/깊이/단면적/속도도0이다. 후속41의 계곡 폭과 이번 수면 폭은 서로 다르며, 새 계곡 절개 지형을 수문 모형에 채택하지 않는다.

이 식은 얼음이 없는 정상 등류의 단면 후보다. 홍수터 넘침·후방수위·가변 조도·빙결에 따른 통수 저하·실제 개별 함몰부 방류량을 재계산하지 않는다. 지도 선굵기는 화면 표시용이며, 지상 폭은 숫자와 단면에서 확인한다.

## 적설 물량과 깊이

모든 격자에서 빈 눈 저장으로 시작해 원본12기간을10번 반복한다. T≤0°C이면 그 기간의 강수를 모두 강설로 쌓고, T>0°C이면 `min(남은SWE,45×T)`mm를 녹인다. 매년 저장을 초기화하지 않는다.10년차 각 기간 말 SWE와 연간 장부 `시작+강설−융설=끝`을 기록한다. 원본의 임계값·융설 지수를 재사용한 독립 눈 기둥이며, 후속40의100년 말 눈 상태를 대체하지 않는다. 증발·승화·바람 재분배·빙하 이동/유출·액체 보유는 여기에서 생략했다.

SWE의1mm는1kg/m²다. 가정 밀도250kg/m³로 나누어 깊이m를 계산하고,100/400kg/m³의 깊이 범위를 제공한다. 고정 벌크 밀도이며 층별 압밀/융해 재결빙/빙하 밀도를 구한 것은 아니다. 연간 잔여가 양수인4,852격자는 `perennialAccumulation:true`, `glacierDynamicsModeled:false`로 표시한다. 최대469.38m의 고정밀도 환산값도 숨기지 않는다. 이는10년간 축적/이동 생략에 따른 모델 눈 기둥이며 실제 평형 눈 두께나 빙하 형상이 아니다. 호수 격자의 눈 값은 그 위치의 가상 눈 축적 가능량으로 표시하고 육지 적설 면적에서 제외한다.

## 수온·잠열·결빙

단위 수면적당 엔탈피E를0°C 액체 기준으로 계산한다. E>0은 물의 현열, -ρH L≤E≤0은 물/얼음 혼합 잠열, 그보다 낮으면 열교환층 전체가 언 뒤 얼음의 현열이다. 물 밀도1000kg/m³, 얼음917kg/m³, 물 비열4186J/kg/K, 얼음2100J/kg/K, 융해잠열334kJ/kg를 가정한다. 질량으로 제한한 얼음 두께와 액체/고체 온도를 분리하므로 물량보다 많은 얼음을 만들거나 한계를 넘은 냉각 에너지를 버리지 않는다.

순열량은 대기 교환 + 하천 이류 + 바닥 열이다. 대기 교환은 `g(Tair−Tphase)`이며 물 표면의g는20W/m²/K다. 얼음이 생기면 공기 경계/얼음/눈의 열저항을 직렬 합산한다. 얼음/눈 열전도율은2.2/.3W/m/K다. 주위 눈 기둥 평균 깊이의25%, 최대.5m를 단열 눈으로 가정하고, 처음5cm의 얼음 성장 동안 연속적으로 눈을 보유시킨다. 갑작스러운 단열 전환으로 얇은 얼음이 수치적으로 생겼다 사라지는 문제를 줄인다. 열교환의 모든 반복 해에는 계산된10년차 눈 주기를 동일하게 적용한다. 눈 무게·얼음 위 실제 적설 장부는 결합하지 않았다.

하천 이류 열은 `ρ cp Q / (연평균 수면 폭×구간 길이) × (Tin−max(Tphase,0))`다. 기준 Tin은 `max(.5°C,Tair)`, 바닥 열은2W/m²다. 세 경우는 기준 / 단열 눈0 / 유입 수온 하한2°C다. 하천의 기준 수면 폭·수심은12기간 평균 유량으로 정하고, 열교환층은 그 수심과2m 중 작은 값이다. 유량0인 기간에도 이 기준 수면을 고인 물로 유지한다. 연중 유량이 모두0인 구간은 열교환층 자체가0이다. 계절 개수로 폭과 결빙 기준 수면은 별도 진단이며 합성하지 않는다.

반복10년의 마지막 해를 출력한다. 외부 순복사는 비교 가정0W/m²이며 일사·구름·장파·바람을 독립적으로 풀지 않는다. 대기 교환계수는 이 단순화된 열 경계의 가정이다. 입력 유량은 얼음에 반응하지 않으므로 얼음이 통수능을 줄이는 실제 결합 계산으로 해석하지 않는다. 열교환층 전체 동결은 해당 모델층의 상태이며 수체 전체 동결과 다르다.

## 수치 비교와 경계

기간당120단계(약6.08시간)를 표시한다. 별도60단계와 전체64,779열주×3조건×12기간을 비교했다. 면적/하천 길이의 차이는 모든 조건·기간에서1% 이내지만, 지점별 두께 최대 차이는 약.269m다. `numericalIceRangeM`는 두 시간 간격 결과의 범위이고 물리적 신뢰구간이 아니다.1cm 기준의 결빙/비결빙이 달라지는 지점은 `extentThresholdStable:false`, 지도에서는 황색이다. 열수지 보존과 수치 수렴, 물리적 정확성은 구분한다.
