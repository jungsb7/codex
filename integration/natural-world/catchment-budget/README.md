# D193196 집수권 물수지 — 후속13

[상세 지도](index.html) · [결과 보고서](REPORT.md) · [전체 집수권 지도](../unified-atlas/index.html#mode=drainage&cell=239286&lon=102.7734375&lat=53.5546875&zoom=8)

전 대륙 기존 경계 유입량1위 D193196의5,170개 집수 격자를 계측하고, 함몰 지형2,131격자를47개 지형 웅덩이로 나누었습니다. 원본 강수·증발산·눈·눈 이외 저장·발생 유출을62,040개 격자-기간 장부로 확인합니다. 실제 호수47곳을 확정한 것이 아닙니다.

## 조회

전 대륙 지도의 수계 검증에서 D193196 집수권 격자를 선택하면 **이 격자의 물수지·웅덩이 상세**로 연결됩니다. 선택한 격자 ID를 그대로 유지합니다. 상세 화면에서 지도 클릭·드래그·휠·확대 버튼·방향키, 웅덩이 ID검색·유입량순 목록·페이지 이동, 원본12기간·연간 합계, 수송 구간 평균, 강수·유출·PET공백 보기, JSON저장·주소복원·모바일 조회를 지원합니다.

집수권 전체/선택 웅덩이 집수권/선택 격자의 표는 서로 포함 관계입니다. 세 열을 합산하지 않습니다. 작은 저장 변화는m³로 표시합니다. 범위 밖 격자는 다른 지점으로 바꾸지 않고 범위 밖으로 표시합니다.

## 원본을 계측한 방식

원본 HTML의 메모리 사본에 상태 읽기만 추가했습니다. 일반식은6년차(4,481격자), 북방 수원식은60년차(689격자)의 마지막 원본 계산연도를 계측했습니다. 두 분기의 연도를 같은 물리적 시점으로 취급하지 않습니다. 원본 산술·입력·파일은 수정하지 않았고 전 세계268,857격자×12기간 발생 유량이 기존 수집본과 바이트가 같습니다. 세계·지형 해시와 전역 물수지도 일치합니다.

일반식의 ground는 토양·얕은 지하수 통합 저장입니다. 개별 토양/대수층 저장은미정입니다. 북방 수원식은 모형의 토양·지하수·상류 이동 저장을 구분합니다. 화면·JSON에서 이 두 의미를 분리하며 실제 지하수량은 여전히null입니다. Float64 자료의NaN은 분리 불가/해당 없음이고 조회JSON에서는null입니다.

원본 발생 유출은Float64 산술, 기존 수송 입력은Float32 저장값입니다. 반올림 차이를 별도 항목으로 보존합니다. 수송 구간은현재·다음 원본기간의 평균이며 모든 유량·저장 변화 항목에 같은 규칙을 적용합니다. 시작/종료 저장 스냅샷은 평균하지 않습니다. 연말 눈을0으로 초기화하지 않습니다.

## 지형 연결과 범위

같은 고도의 평탄부를 먼저 묶고 원본8방향의 최대 하향 경사로 낮은 지형을 구분합니다. 기존 외부 유입 경로는 실제 진입 격자에서 해당 웅덩이로 연결하고 각 격자의 원본 발생량을 한 번 배정합니다. 가장 낮은 인접 문턱과 최소 연결 트리46개를 기록하고 독립 임계수위 연결 검사로 대조합니다. 지도 점선은 이 지형상 유입 경로 가설입니다.

약26km 격자는 소하천·제방·골짜기 폭이나 실제 물길의 세부 선형을 결정하지 못합니다. 저류 시작값·500년 반복 실험·새 증발산·침투·수면전환 가정을 추가하지 않았습니다. 출구296.228m와 다음D191657 경계는 기존 연결 가설이며 실제 방류는null입니다. 다른19개 함몰부의 조건부 상류 연결은 이번 원본 유입에 합산하지 않았습니다.

38°C 초과PET공백511격자는 식생/건조도 선별의 결측입니다. 이 격자들은 일반식의 별도 증발 계산에서유출0을 산출합니다. 이를 실제 유출0의 인증이나 PET공백 해소로 취급하지 않습니다. JSON의ecologicalPET는 고온 보류와 이 원본 물수지에서 추출하지 않은 항목을 구분합니다. 공백 밖의 생태PET 수치를 이번 원본ET와 혼합하지 않습니다.

## 재현

전체 인계 폴더의 저장 입력을 사용합니다. 공개 사이트에는 화면 실행 자료와 결과 요약이 포함됩니다. 원본 계측 재실행은Playwright/Chromium·로컬HTTP가 필요합니다.

```sh
node integration/natural-world/catchment-budget/collect.cjs
node integration/natural-world/catchment-budget/build.cjs
node --test --test-isolation=none integration/natural-world/catchment-budget/test.cjs
node integration/natural-world/catchment-budget/browser-check.cjs
```

수집 입력이 있으면collect는 생략합니다. 이전 단계build/record/verify를 실행해 최신 산출물을 덮어쓰지 않습니다. 이번build는 자신의output만 갱신합니다. 배포 여부는validation/deployment.json과integration/STATE.json에서 별도로 확인합니다.
