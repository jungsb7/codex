공통 확인: 타일 이음새·등고선·물길 밀도·숲/습지 가장자리·기호/지명/원본 격자 겹침을 비교했다. 원본 격자 토글, 기존 설정만 보기, 설계 표시 안내를 72조건에서 검사했다. 화면 안에 선택 가능한 선이 있는 경우 실제 표시 경로의 좌표를 클릭해 선택 강조·정보창 ID 일치를 확인했다. 선이 없는 뷰는 `selection: null`로 기록했으며 가상의 선택 대상을 만들지 않았다. 12대표의 좌표/자연물/계절 JSON은 같은 선택 지점을 가리킨다. 바다에 닿는 기존 자연물의 선택점에는 육지 계절값을 만들지 않고 `ocean`과 `null`을 유지한다.

원본 격자 경계에서 생기는 해안 계단, 후보/보류 마스크 경계, 일부 직각 수계선은 남는다. 이것은 새 지형을 채택하지 않는 이번 표시 작업의 범위다. 실제 산림·습지 면적·침수·강폭·결빙, 미정 하류 상태는 바꾸지 않았다.
