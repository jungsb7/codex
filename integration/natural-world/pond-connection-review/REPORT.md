# P237734가 닿는 곳은 두 웅덩이만이 아니다

P237734의 첫 연결 상대는 P231591이다. 그러나 P231591은 더 낮은 문턱을 통해 다른 7개 지형 웅덩이와 연결 가능하다. 첫 연결 높이 260.231658936m에서 완전한 지형 연결 집합은 **9곳**이다. 두 곳만 합치면 1,075개 집수 격자와 연간 37.612615km³의 원본 유출을 빠뜨린다.

이 결과는 공통 수위를 가정한 정적 지형 연결이다. P237734에서 처음 넘친 물이 낮은 이웃 전체를 즉시 그 수위로 채운다는 뜻이 아니다. 초기 저류·개별 수위·채워지는 순서와 시간·연결부 유속을 알 수 없으므로 실제 동적 연결은 미정이다.

원본 고도 격자의 D8 연결 경로에서 가장 높은 높이가 가정 수위 이하이고, 해당 격자 고도가 수위보다 낮을 때만 포함한다. 단순히 낮은 칸을 모두 모으지 않는다. 독립적인 전체 바닥 격자 범람 검사로 첫 연결 집합과 다음 경계를 확인하고, 모든 고도 전환점에서 제한된 9곳의 범람 결과를 대조한다.

다음 경계는 P231591–P237726 사이 266.318939209m다. 정확히 이 높이에서는 전체 지형 연결 집합이 10곳으로 바뀐다. 이번 UI 상한은 **10번째 곳을 추가하기 직전 9곳의 기하학적 한계**로 표시한다. P237726의 면적·유입·저류를 몰래 더하지 않는다.

각 약 26km 원본 칸을 일정 고도의 수직 기둥으로 취급한 근사다. 부피 차이는 실제 채워진 물·추가 저류·홍수량이 아니며, 실제 저수용량·해안선·수심 분포도 미정이다. 지도는 원본 격자의 배치이며 거리 비례 투영이 아니다.

## 수면 가정의 물수지

침수 가정 면적의 기존 육지 유출·증발산·눈 이외 저장 변화를 분리해 제거한다. 남는 육지 유출에 수면 면적의 강수를 한 번만 더하고, 원본 국지 눈 장부를 유지한 산술 참고값을 계산한다.

```
L = 남는 육지 유출 + 수면 강수 − 원본 국지 강설 + 원본 국지 눈 녹음
L + 원본 국지 눈 변화 + 원본 국지 승화 = 남는 육지 유출 + 수면 강수
R = L − 가정 수면 증발
R = 미정 액체·얼음 저장 변화 + 지하수 순유출 + 외부 방류
```

첫 연결 높이에서 L은 261.726818km³/년이다. 증발 2,000mm/년을 가정하면 135.558819km³가 빠져 R은 126.167999km³/년이다. R을 실제 방류나 저장 증가로 배정하지 않는다. 9곳 사이의 내부 교환은 전체 장부에서 상쇄되지만 개별 방향·유량·시점은 여전히 미정이다.

원본 눈 장부를 유지하고 다른 변화·교환·유출을 모두 0으로 놓아 증발만으로 맞추는 필요 깊이는 첫 문턱에서 약 **3.861m/년**이다. 한 곳만의 109.019m/년과 큰 차이가 난다. 이는 계산 범위를 바로잡은 결과이며, 3.861m/년을 실제 가능한 증발로 인증하거나 폐쇄 호수의 존재를 확정한 것이 아니다. 새 수면의 기후·열수지·결빙·지하수 교환이 필요하다.

증발은 기본 null이다. UI에서 0·1,000·2,000·5,000mm/년을 선택할 수 있고, 주소로 들어온 0~5,000 범위의 값도 가정으로 표시한다. 선택값을 12개 동일 길이 기간에 균일 배분한다. 실제 에너지·얼음 제약을 반영한 증발 예측은 아니다. 원본 육지 강수·눈 계산을 새 수면에 적용하는 기후 피드백 생략도 명시한다. 기존 저장 재고를 새 초기 저류로 옮기지 않고, 연말 눈을 초기화하거나 500년 반복하지 않는다.

## 눈과 시점

원본 눈 증가가 연간 1m³를 초과하는 66격자는 모두 450개 바닥 격자 밖에 있다. 눈은 물 환산 저장이고 실제 빙하·얼음 두께와 다르다. 원본 일반식 6년차와 북방 수원식 60년차는 같은 실제 연도가 아니다. 두 달력을 같은 물리적 시작 시점으로 간주하지 않는다. 계절 표시는 원본 12기이며 새 호수의 체류시간·방류 지연을 계산하지 않았다.
