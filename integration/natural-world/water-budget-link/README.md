## 재사용한 근거

`surface.cjs`는 후속24의 수면 전환 적분기를 바탕으로 수신량과 내부 저장 이동 항을 추가한 별도 모듈이다. 원본 육지 산술은 기존`step`을 직접 재사용한다. 수신0일 때 기존 적분기의 모든 공통 총량과 최종 재고/젖은 격자가 정확히 같아야 한다.

## 상류 수신과 시간 가정

D301678과D307820이 각각 물리 진입 격자303208/304744로 전달하며, 둘 다 기존 웅덩이303204에 들어간다. 두 송신 경계에는 다른 상류 경계가 없다. 이 조건이나 진입점이 바뀌면 계산을 거부한다. 송신 경계의 기존 집계 재고를 기간별로 재현해1,200기간 전달량을 만들고 후속32 전역 실행의 송신 누계 및 마지막12기간과 대조한다.

네트워크의 유입은 인접 위상 평균값이고 지역 수분 장부는 원시12위상이다. 두 자료를 같은 번호에 대응시키는 **명시적 혼합 강제력 실험**이다. 동시 관측 수문곡선이나 지구 달력 월이 아니다. 각 기간의 상류 수신량은30하위단계에 균등 배분한다. 유하 시간·하도 손실·역수위는0/없음 가정이며 원본receiver를 수정하지 않는다.

## 물량 항목

마른 격자는 원본 눈·얕은 저장·유출·증발산 산술을 따른다. 잠긴 격자는 육지 유출과 육지 증발산을 끄고 강수/융설을 수면에 한 번만 넣는다. 눈 수량과 혼합 얕은 저장은 상태로 보존한다. 잠긴 칸의 얕은 저장은 유지하고 드러나면 계산을 재개한다.

```
강수 + 상류 수신
= 육지 증발산 + 수면 증발 + 외부 지하수 순손실 + 문턱 초과 전달
  + Δ눈 + Δ얕은 저장 + Δ수면 재고
```

추가한 내부 이동 항:

- `shallowRechargeM3`: 원본 산술에서 즉시 증발 후 액상 물량의35%가 혼합 얕은 저장으로 이동하는 양.
- `shallowReturnM3`: 혼합 얕은 저장에서 유출로 돌아오는 기저 방출량.
- `shallowEvaporationM3`: 혼합 얕은 저장에서 나가는 증발산. 이미육지증발산에포함되므로외부손실에다시더하지않는다.
- `directRunoffM3`: 나머지65%의 직접 유출. 기저 방출과 합쳐육지유출이다.

`Δ얕은 저장 = recharge − return − shallow evaporation`을 별도 검사한다. 이 항들은 내부 이동이며 강수/외부 유입에 새로 더하지 않는다. **35%는 원본 분배 규칙이지 측정된 침투율·투수계수가 아니다.** 원본의혼합저장을토양/대수층으로나누지않으며`actual.infiltrationM3`는null이다. 예제에서 얕은 저장 증발산0은 해당모형의계산결과이며 누락값을0으로보충한것이아니다.

수면 증발0.5/1/2m/년과 외부 지하수 순손실0/0.25m/년은 그때 모델상 젖은 면적에 적용한다. 외부 지하수 손실은 계산 밖 저장으로 나가는 가정 유출이며 혼합 얕은 저장의 recharge와 다르다. 실제 침투율/수면 열수지/지하수 수위는미정이다.

## 기존 네트워크 장부의 교체

후속32 전체 결과에서 D298591의 기존 원본 집계 유입·추가 순손실·초기/종료수면재고·해양전달을 제거하고 새 강수·증발산·수면증발·외부손실·눈/얕은저장/수면재고·초과전달로 교체한다. 상류 수신은 기존망의 내부 전달이므로 전역 외부 유입에 다시 더하지 않는다.

```
교체 후 외부 유입 = 다른경계의 기존 발생량 + D298591 강수
교체 후 초기/종료 재고 = 다른경계의 집계재고 + D298591 눈/얕은저장/수면재고
```

따라서 전역 외부 유입은 행성 전체 강수량이 아니다. 다른경계는출력단면을,이유역은619격자전체를포함하는혼합계산영역이다. 처리 미정 물량은 그대로 보존한다. 원래D298591방류를한번빼고새초과전달을더한**차이**만 기존62격자 해양경로에 반영한다. 음의차이는기존예상증분의감소이며역류가아니다. 기존하류발생량을포함한총유량도아니다.
