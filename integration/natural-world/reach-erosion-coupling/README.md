# 개별 물길 유량과 침식·퇴적 — 후속52

공개 게시와 분리한 로컬 구현이다. 기존103년 말 물·눈·얼음 상태에서 고정 기후1년(104년)을 이어간다. [가정](assumptions.json)을 먼저 읽는다. 120/240단계와 침식0 대조를 같은 초기 상태로 비교한다. 세 전체 계산과 자료/브라우저 검증을 완료했다. 결과와 한계는 [REPORT](REPORT.md)에 기록한다.

23,022개 원본 구간과 원래 상하류 관계를 보존한다. 대상 육지168,576칸 중91,112칸의 유출은 원래 하류 경로에서 처음 만나는 대상 물길에 들어간다. 물길을 만나지 않는77,464칸은 원래 저류칸에 남는다. 수면 위 직접 강수도 원래 저류칸으로 간다. 각 구간의 유입은 해당 격자 유출과 실제 상류 방출의 합이며 집수권 총량을 복사하지 않는다. 끝 구간은 원래 종점 저류칸의 수두를 경계로 쓴다.

직사각 단면의 폭은 원본 평균유량으로 고정한 `2+2sqrt(Q)`m다. 계산 수량/폭/길이로 수심을 구하고 Manning n=.035로 가용 수량에 제한된 암시적 방출을 푼다. 원래 방향만 흐르는 운동파 저장 근사이며 역류·전 운동량을 풀지 않는다. 침식/퇴적은 별도 채널 하상의 높이를 바꿔 경사와 방출에 되먹임한다. 원래 채택 지형과 저류 지형은 덮어쓰지 않는다.

활성 하상은1m,건조 벌크밀도1600kg/m³의 유한 재고로 시작한다. 임계 전단2Pa 초과분에1e-5m/Pa/년을 곱해 침식한다. 유량0에서 침식은 정확히0이다. 부유사는0.001m/s의 침강으로 하상에 돌아가며, 실제 이동한 액체 비율만 하류로 옮긴다. 말단의 퇴적물은 저류칸 퇴적 재고에 남고 사라지지 않는다. 압밀·융해·결빙과 동토 제한은 후속51의 같은 장부에서 계속 계산된다.

각 구간의 매 기간 시작+현지유입+상류유입−방출=끝 수량, 하상+부유사+상류유입−하류수송=끝 고체량을 확인한다. 전체 물수지에는 채널 저장을 여섯 번째 재고로 더한다. 원본/채택판/후속51이전 결과는 보존한다.

```sh
node integration/natural-world/reach-erosion-coupling/compile.cjs /tmp/node-v24.19.0/include/node
node --test --test-isolation=none integration/natural-world/reach-erosion-coupling/test-engine.cjs

```

전체 계산은 `/workspace/reach-erosion-cache-52`에 코드/초기자료 해시와 함께 보관한다.16GiB에서는 반드시 순차 실행하며 살아 있는 계산을 중복 시작하지 않는다. 저장소에는 필요한 결과와 계속 계산 상태만 무손실로 보관한다.

한계: 관측 토질/강폭/세부 지형이 아니다. 채널 간 순차 풀이의 시간 민감도를 공개하며 이전 수위 시간4.282m·공간14.574m 민감도도 유지한다. 1년의 하상 변화가 실제 장기 지형 진화나 평형을 증명하지 않는다. `actual:null`, `automaticAdoption:false`, `allRequestedDetailImplemented:false`를 유지한다. 공개 GitHub/PR/Pages는 승인 대기로 작업하지 않는다.

지도·CLI는 같은 `core.js`의 구간 조회와 집수권 물수지 함수를 사용한다. `node query.cjs 48 7`, `node query.cjs budget world 7`로104년7기간을 읽는다. 지점/집수권/연중 JSON을 내보낼 수 있으며 기간 유량은 해당 기간에 실제 방출된 양을 기간 초로 나눈 평균이다. 순간 홍수 첨두가 아니다.
