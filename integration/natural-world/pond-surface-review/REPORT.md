# P237734: 작은 폐쇄 호수로 확정하기 전에

P237734로 모이는 원본 발생 유출은 연간 218.800km³이다. 첫 이웃 연결 문턱 아래의 후보 수면은 원본 격자 기준 약 2,008.433km²에 불과하다. 원본 국지 눈 장부를 유지하고 다른 저장 변화·교환·방류를 0으로 놓아 증발만으로 맞추려면 약 109.019m/년이 필요하다. 이 수치를 실제 증발로 채택하지 않는다. 현재 원본 유입을 그대로 적용해 작은 폐쇄 호수로 확정할 근거가 부족하다는 진단이다.

## 원본 장부와 눈의 위치

| 항목 | 원본 연간 값 |
| --- | ---: |
| 집수 격자 | 286개 / 121,364.904km² |
| 강수 | 285.411km³ |
| 증발산·승화 | 29.508km³ |
| 발생 유출 Float64 | 218.799813707km³ |
| 기존 경계 유출 Float32 환산 | 218.799813850km³ |
| 눈 저장 증가 | 37.103km³ 물 환산 |
| 눈 이외 저장 변화 | 25.941m³ |

일반식 189격자는 원본 6년차, 북방 수원식 97격자는 60년차다. 같은 실제 연도가 아니므로 스냅샷을 새로운 초기 호수 저류로 사용하지 않는다. 북방 수원식의 기존 유출 기여는 98.87%이다. Float64와 Float32 유출 차이 약 143m³/년은 기존 정밀도 차이로 보존하며 이번 대수적 물수지는 Float64로 계산한다.

연간 눈 증가가 1m³를 초과하는 21격자는 모두 북방 수원식이 적용된 바깥 집수권이다. 74개 지형 바닥 격자 안에는 없다. 후보 수면 5격자의 원본 눈은 연간 강설과 녹음이 같고 승화는 원본 일반식에서 0이다. 눈 저장량은 물 환산값이며 빙하나 얼음 두께가 아니다. 영하 기온이 있어도 새 수면의 수온·열교환·눈덮임·얼음을 계산하지 않았으므로 실제 결빙은 미정이다.

## 지형 가정

최저점은 254.841796875m, 첫 연결은 P231591 방향 260.231658936m이다. 각 바닥 격자의 최저 연결 높이를 D8 minimax로 계산한다. 수위 이하로 연결되고 고도가 수위보다 낮은 칸만 양의 수심으로 포함한다. 독립 D8 범람 검사로 고도 전환점에서 검증한다.

문턱에 닿는 한계에서 237733·237734·237735·237736·239270의 5격자가 포함되고, 면적 2,008.433km²·기하학적 부피 5.987986km³이다. 문턱 격자 자체의 수심 0은 면적에 포함하지 않는다. 이웃 P231591의 유입·면적·저류는 더하지 않는다. 이 값은 약 26km 높이 표본을 격자 전체에 적용한 수직 기둥 근사이다. 실제 저수용량, 해안선, 홍수 면적, 물이 차는 시간은 아니다. 낮은 수위에서도 격자 면적이 계단식으로 변하며 하위 격자 지형은 알 수 없다. UI 지도는 원본 격자 배치이며 거리 비례 투영이 아니다.

## 육지 항목을 수면 항목으로 교체

침수 가정 면적의 원본 연간 강수는 0.176676km³, 증발산 0.158137km³, 유출 0.018539km³, 눈 이외 저장 변화 0.275913m³이다. 이 면적의 기존 육지 항목을 전부 분리한다. 남는 육지 유출은 218.781275km³다. 침수 면적의 강수를 다시 넣을 때 기존 유출도 유지하면 이중 계산이 된다.

눈 장부를 그대로 둔 산술 참고식은 다음과 같다.

```
L = 남는 육지 유출 + 수면의 비 + 원본 국지 눈 녹음
  = 남는 육지 유출 + 수면 강수 − 원본 강설 + 원본 녹음
  = 218.957951 km³/년 (첫 문턱 한계)
R = L − 가정한 수면 증발
R = 액체 저장 변화 + 얼음 저장 변화 + 지하수 순유출 + 하류 방류
```

마지막 줄은 미정 항목들이 충족해야 할 합계이지 각 항목의 계산 결과가 아니다. 원본 국지 강설·녹음·승화를 유지한 비교이며 실제 새 수면의 눈 장부로 검증되지 않았다. 전체 물 환산 보존식에서도 `L + 원본 눈 변화 + 원본 승화 = 남는 육지 유출 + 수면 강수`를 확인한다. 기존 육지의 저장 재고를 새 수면 초기 저류로 옮기거나, 연말 눈을 초기화하지 않는다.

UI는 증발을 기본적으로 미정으로 둔다. 사용자가 0·1,000·2,000·5,000mm/년을 고르면 매 기간에 1/12씩 배분한 민감도 비교만 한다. 증발 2,000mm/년을 가정하면 4.016866km³가 빠져 214.941084km³가 미정 항목에 남는다. 이 값은 실제 넘침이나 저류 증가가 아니다. 계절 결빙과 에너지 제약을 반영한 증발 추정도 아니다. 원본 육지 강수를 새 수면에 그대로 적용하는 것 자체도 기후 피드백을 생략한 가정이다.

새 초기 저류량·500년 반복·균일 지하수 손실률을 지정하지 않았다. 조건부 상류 함몰부의 방류를 추가하지 않았고, 이동 지연이나 D191657 방류도 계산하지 않았다. 수위 0면적 조건에서는 증발 필요 깊이를 null로 둔다. 범위 밖 좌표를 조회하면 좌표는 보존하고 해당 장부는 null로 둔다.
