# 전 대륙 통합 자연지도 — 후속9

[지도](index.html) · [실행 안내](README.md) · [전 대륙 화면](validation/world.png) · 모바일 (전체 인계 패키지: `validation/mobile-map.png`)

**지형·식생·물길·습지·화산대와 검토 결과를 한 화면으로 통합했습니다.** 기존 세계 설정·계산 후보·보류를 구분하며, 원본 기후·자연물·경제는 변경하지 않았습니다. 검토를 마친 결과를 찾아 여러 화면을 오가던 동선을 줄이는 표시 작업입니다.

## 통합한 자료

육지·기존 호수268,857격자(육지268,648,호수209), 자연 검토11권역 전체입니다. 정치·경제9권역과는 다른 자연 검토 구분입니다. 이전 전 대륙 검토 지도의11개 압축 필드는 바이트 단위로 그대로 복사했고, 고도 음영·기후 범위·기복/경사·지질·유량 후보를 원본 단계 자료에서 읽었습니다.

- 기존 산계16개와 주요 강7개 중심선, 기존 해구·고개를 보존했습니다. 원본 처방의 중심선이며 새 산맥·강을 만든 것이 아닙니다.
- 연결 물길45,824구간의 좌표와 끝점 유형을 유지합니다. 이 중23,022구간은 하류가 내부 배분 미정 경계에 이르므로 점선으로 구별합니다. 구간 수는 강 개수가 아닙니다.
- 화면의 위치·확대에 따라 보이는 물길을 고릅니다. 지구 전체 경계에서 설정한 축척별 조건을 적용하면2,512→10,206→26,490→45,824구간이 대상이 되고 실제 화면 밖 구간은 그리지 않습니다. 늘어나는 것은 표시량이며 새 수계 계산이 아닙니다.
- 습지 후보9,804격자, 화산대 가설214격자는 기존 flags와 분류의 일치를 확인했습니다. 습지 후보의 격자 면적을 실제 침수 면적으로 쓰지 않고, 화산 기호로 새 개별 화산 위치를 만들지 않았습니다.
- 고온 PET24,448격자, 서부 사막 설정 충돌2,629격자, 극지 수분 공백과 전이 판단을 유지합니다. 식생 보류 육지는32,568격자입니다. 기본 자연/식생 보기에서 보류는 사선 무늬로 구분하고 나무 기호를 억제합니다.
- 두 집수권6,850격자·적설 잔여55격자만 국지 수면 검토에 연결합니다. 다른 대륙에 실제 호수52개나 빙하·지하수 경계를 복제하지 않습니다.

숲/정글 토글은 기후 분류6~10(건조 숲초원·열대 계절림/사바나·습윤 열대림·온대림·냉대림)을 함께 다룹니다. 이 그룹63,020격자를 전부 실제 울창한 숲으로 해석하지 않습니다. 초원 토글은 분류5의87,403격자입니다. 지형의 평야 여부와 기후 초원 여부는 별도 층입니다.

## 근거를 구분하는 방식

원본 강 중심선은 밝은 실선, 연결 물길 후보는 가는 선, 하류 배분 미정은 점선으로 표시합니다. ‘기존 세계 설정만’에서는 후보 물길·식생 기호·습지·화산대·검토 무늬/표식을 숨깁니다. 우측 조회는 출처를 구분해 원본과 후보를 함께 읽을 수 있습니다.

지질 보기에서 화산대 표시를 끌 수 있습니다. 실제 화산 위치·활동성은 null로 남습니다. 기존 호수는 원본 수면으로 유지하고, 고온 Oudin 조건부 식생을 기본 식생 위에 덮어쓰지 않습니다. 서부 사막의 원본 유지/B해석 후보도 새 기후로 자동 채택하지 않았습니다.

범위가 맞는 지점에서만 전문 검토 링크를 활성화합니다. 서부 사막은 자연3권역, 고온 PET는38°C 초과 flag, 국지 수면은6,850격자 membership으로 판단합니다. 범위 밖은 비활성 사유를 표시하며 임의의 대표점으로 바꿔 보여주지 않습니다.

## 표시 한계와 성능

원본0.234375°(남북 약26km) 격자를 사용합니다. 확대하면 지류·식생 기호·격자가 추가로 보이지만 더 정밀한 새 지형을 생성하지 않습니다. 원본 격자는12배 이상에서 표시합니다. 기호는 잠재 환경 무늬이며 개별 나무나 미세 하천의 위치가 아닙니다. 기복은 거친3×3 원본 격자, 경사는 기존 stage4 계산값입니다.

강폭·유속·범람·호수 증발·현재 식생 면적·유량을 새로 계산하지 않았습니다. 조회 유량은 원본 수송 모형의 후보이고 함몰부에서 방류로 오인하면 안 됩니다. 실제 식생·습지 면적과 개별 화산 위치는 미정으로 유지합니다. 북방산맥의 열린 통로·D144758 내부 검토 경계·25m절하 보류도 유지합니다.

자료는9.88MB gzip이며 최초에 일괄 로딩합니다. 외부 지도 API/CDN 없이 canvas로 표현하고, 지도 바탕 캐시·화면 경계 검사·축척별 물길 선택·최대1,400개 기호 후보 위치로 표시 비용을 제한합니다. 브라우저 검사의 로컬 첫 표시 시간은11.50초이며 실제 네트워크·기기 성능 보장은 아닙니다. 이전 기본 자연지도는57.1MB 압축자료를 사용했으며 이 화면은 계절 전체 장부를 포함하지 않는 다른 범위의 표시판입니다.

## 검증과 보존

8개 빌드 검산·12개 자료/조회 검사·12개 브라우저 검사, 합계32개를 통과했습니다. 원본 압축 필드·세계해시·출처 해시,호수/해양/null, 후보 숨김, 식생 보류 기호 억제, 축척별 물길, 좌표 링크 적용 범위,6,850격자 국지 제한을 검사했습니다.

브라우저에서는6보기, 레이어 토글, 기존 설정만 보기, 원본 격자, 좌표 JSON, 같은 셀의 서부 사막·고온 PET·국지 수면 실제 페이지, URL/뒤로 가기, 모바일과 두 손가락 확대를 확인했습니다.
