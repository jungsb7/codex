## 지도 조작과 근거 연결

대표 표식과 전체 격자 강조를 구분합니다.11권역과 검토 항목을 교차 선택하고, 좌표를 클릭하거나 입력하면 원본 고도·지형/식생/습윤 후보·각각의 검토 상태·채택 조건·이전 분석 링크를 볼 수 있습니다. 국지 분석으로 이동할 때 같은 격자를 선택합니다. 좌표 JSON 내보내기, URL 상태 보존, 뒤로 가기, 키보드 이동, 모바일 배치를 지원합니다.

전체 자료를 1,904,828바이트 gzip으로 묶었습니다. 테스트 환경의 초기 로딩·해제·조회 준비는 약1156ms였습니다. 단일 로컬 측정으로 실제 원격 속도를 보장하지 않습니다. 기존 자연지도 자료 전체를 다시 읽지 않지만, 이번 묶음은 최초에 일괄 로딩합니다.
