2026-10-19 기준. [기존 지도](../unified-atlas/index.html) · [현황 화면](status.html) · [기계 판독 현황](output/project-status.json).

**전 대륙 후보 지도와 원래 설계의 기본 6단계 구현은 완료했다.** 268,857개 육지·기존 호수 격자, 자연 11권역을 같은 기준으로 조회할 수 있다. 지형·잠재 식생·물길·습지 후보·화산대 가설·검토 상태를 보는 지도와 GitHub Pages 배포가 있다.

이것은 모든 숲·습지·호수·개별 화산을 확정 설정으로 채택했다는 뜻이 아니다. 최근 후속 작업은 국지 수계의 물리 검토에 집중되어 전체 후보 지도 구현의 종료와 구분되지 않고 길어졌다. 앞으로 완료 기준을 다음처럼 나눈다.

현재 국지 검토는 다음 최종 정리에서 종료한다. P237726 이후를 계속 따라가거나 모든 함몰부의 실제 방류를 해결해야 끝나는 과제로 바꾸지 않는다. 실제 물리량을 null로 남기는 것은 검토 결과이며, 누락된 연구를 몰래 완료 처리하는 것은 아니다.

## 이미 제공하는 후보 자료

- 숲·정글 관련 기후 분류 그룹 63,020격자, 초원 분류 87,403격자. 실제 산림 면적이나 개별 나무 수가 아니다.
- 습지 후보 9,804격자, 화산대 가설 214격자. 실제 습지 면적과 개별 화산 위치·활동성은 미정이다.
- 물길 후보 45,824구간. 강의 개수가 아니며, 23,022구간은 하류가 배분 미정 경계에 닿는다.
- 기존 호수 209격자와 기존 산계·강의 세계 설정은 그대로 보존한다.

**전체 완료율을 90% 같은 숫자로 제시하지 않는다.** 지도 기능 구현, 격자 적용 범위, 자연물 채택, 물리적 확실성은 서로 다른 척도이고 아직 공통 완료율의 분모를 정하지 않았다. 사용 가능한 후보 지도의 1차 구현은 완료, 현재 9곳 검토는 마무리 1회, 모든 자연물의 실제 상세 확정은 별도 후속 과제다.
