# 9곳 수면을 증발만으로 유지할 수 있는가

첫 연결 높이에서 필요한 증발량 3.861m/년을 액체 물의 잠열로 환산하면 약 **299.992W/m²**다. 이 면적의 연평균 대기 상단 입사 태양에너지는 약 **263.649W/m²**다. 대기 상단에 들어오는 단파를 100% 증발에 사용해도 부족한 비교값이며, 추가 열 공급을 설명하지 않고 증발만으로 닫히는 호수라고 확정할 수 없다.

이는 모든 조건에서 증발이 불가능하다는 증명이 아니다. 대기의 하향 장파·현열, 유입수의 열 수송, 저장열 등이 존재할 수 있으나 여기서는 자료가 없으므로 미정이다. TOA는 지표 순복사가 아니고, 실제 지표에서는 투과·반사·열 방출과 수온 변화도 고려해야 한다.

## 물수지에서 열량으로

이전 단계의 원본 육지 장부 제거와 국지 눈 장부 유지 산술 공급 L을 그대로 사용한다. 다른 저장 변화·지하수 교환·방류를 0으로 놓아 증발만으로 맞추는 진단값이다. 실제 해당 항목을 0으로 설정하지 않는다.

```
필요 증발 깊이 mm = L(m³) / 후보 면적(m²) × 1000
필요 잠열 W/m² = 깊이(mm) × 2,450,000(J/kg) / 기간 초
1mm 물 = 1kg/m²
```

액체 물의 증발 잠열은 2.45MJ/kg로 고정한 참고값이다. 온도별 잠열 변화, 눈·얼음 승화와 융해 에너지를 더하지 않는다. 연간은 365일, 각 원본 기간은 365/12일이다. 사용자가 고른 증발 0·1,000·2,000·5,000mm/년도 같은 방법으로 환산한다. 기본 미정은 null이며 명시적 0과 구분한다. 2,000mm/년 가정의 잠열은 약155.38W/m²다.

기간별 필요 잠열을 단순히 연간 값과 혼합하지 않는다. 각 기의 부피·면적·기간 길이로 환산하고, 연평균 잠열은 동일 길이 12기 평균이다. 연간 부족량은 연간 필요 잠열과 연평균 TOA의 차이로 구한다. 계절별 양의 부족량만 더해 연간 부족으로 만들지 않는다. 계절 사이의 저장열 이동은 계산하지 않는다.

## 일사와 기온의 시점

기존 앱의 태양상수1361W/m², 자전축23.4°, 이상 원형 궤도와365일을 따른다. 기존 `solarAt`와 동일한 일평균 대기상단 일사식을 쓰고, 각30° 구간의64개 중점 표본을 평균한다. 일조 시간의 극야·백야 경계를 포함한다. 면적은 원본 위도별 격자 면적으로 가중한다.

기온은 원본 육지 대기 계산의 각 기 시작 위상(0°,30°,…330°) 표본이다. UI는 이를 해당30° 구간 평균 TOA와 구분해 표시한다. 기온을 새로운 수면의 수온으로 쓰지 않는다. 원본 일반식6년차·북방 수원식60년차는 같은 물리적 연도가 아니다.

영하 표본 면적비는 그 기에서 대기 기온 표본이0°C 미만인 후보 격자의 면적비다. 연간 영하 환산일과 동결도일은 각 표본이365/12일 동안 일정하다는 근사다. 실제 결빙일, 얼음 면적·두께, 빙하 확정값이 아니다. 얼음 덮임·수온·수심별 혼합·바람·습도·지표 순복사·대수층은 계속 미정이다.

## 전체 진행 상태와 종료 범위

전 대륙 후보 지도와 원래 기본6단계 구현은 완료되어 있다. 실제 자연물 채택까지 완료된 것은 아니다. 정확한 범위·미정 수·중복 주의는 [프로젝트 현황](PROJECT_STATUS.md)과 그 입력 해시를 참조한다. 전체 완료율의 공통 분모가 없어 임의 백분율은 표시하지 않는다.

이번 열수지 비교 뒤 현재9곳 국지 검토에는 **결정 기록 최종 정리 1회**만 남긴다. 검증된 지형 진단과 실제 호수·얼음·지하수·방류의 보류 사유를 일관되게 안내하면 이 국지 검토를 종료한다. 새로운 함몰부나 완전한 열역학 모형을 계속 필수 범위에 추가하지 않는다. 실제 자연물의 추가 채택·기후 수정·미세 지형은 별도 후속 작업이다.
