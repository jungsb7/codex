# 집수권 사이의 물 교환과 원본 입력 일괄 확보

후속38은 두 중단 경로 `D221625 → D200167`, `D258447 → D243078`을 포함해 기존 57경계 안에서 원본 지형으로 발견되는 추가 접촉을 **후보 연결**로 계산한다. 원본 수계는 그대로 보존한다. [화면](index.html) · [결과](REPORT.md).

## 범위

946경계·20,065구간·117,320격자에 대해 원본 강수·기온 12위상과 시작 저장을 한 번에 수집했다. 이전 57경계의 11,355격자와 겹치는 값은 모두 정확히 일치한다. 원본 전 세계 지역 유출의 SHA-256과 전체 물수지도 일치한다. 수집 중 원본 HTML·앱 파일을 수정하지 않고 메모리에 만든 계측 사본만 실행한다.

| 범위 | 상태 |
|---|---|
| 57경계·2,637구간 | 원본 입력으로 지형·양방향 출구의 동적 계산 |
| 나머지 889경계·17,428구간 | 지형·강수·기온·초기 저장 확보 완료, 동적 계산은 실행 전 |
| D298591 연결망 3경계·190구간 | 기존 연구 보존, 적용 제외 |
| 기존 보류 235경계·2,767구간 | 보류 유지 |

946경계 중 69곳에는 북부 전용 모형의 2,241격자가 포함된다. 북부는 눈·토양·지하수·상류 이동 저장의 네 항을 별도로 기록한다. 기존 육지의 혼합 얕은 저장으로 합치거나 기존 200mm/1000mm 엔진으로 자동 치환하지 않는다. 북부 초기 상태는 원본 60번째 연도의 시작이고, 나머지 지역은 원본 여섯 번째 연도의 시작이다. 이들은 실제 관측 또는 지구 달력 월이 아니다.

기존 10.2MB 계측은 57경계 계산에 재사용한다. 전체 입력은 중복된 월별 저장 스냅샷 대신 12위상의 강수·기온과 한 번의 초기 저장을 담은 gzip 23,484,677바이트로 보관한다. 600,000바이트 이하 조각으로 나누고 각 조각과 전체 SHA-256을 검증한다. 분할은 전송·검증 편의이며 원본 지형을 단순화한 것이 아니다.

## 후보 지형과 연결

원본 D8 격자에서 같은 집수권의 연결 가능한 기둥을 찾는다. 기존 하류뿐 아니라 동적 계산 중인 57경계 안의 다른 집수권 접촉도 출구 면으로 모은다. 기둥의 소유권과 강수 배정은 서로 겹치지 않는다. 57경계 밖의 다른 집수권·호수·다른 해양 지점은 계속 중단 경계다. 같은 해양 종착점으로 가는 원본 경로는 기존 계산처럼 바다 수신으로 처리하며 해안 이동 시간을 계산하지 않는다.

검색 상한은 기존 기준 문턱 위 5m 그대로다. 발견된 면으로 물을 보내는 계산 없이 상한만 올린 것이 아니다. 연결되지 않은 외부 접촉을 무시하거나 원본 수계를 바꾸지 않는다. 양쪽 물량은 실제 출구 격자의 원본 배정 웅덩이로 전달한다.

경계별 총 설계 폭 `max(10,4Qref/1.5)`을 해당 경계에서 발견한 모든 면에 나눈다. 양쪽에서 같은 물리 격자 면을 발견했다면 면을 한 번만 만들고, 제안된 폭의 작은 값과 문턱의 큰 값을 사용한다. 총 폭을 면 수만큼 늘리지 않는다. 새 면에 폭을 나누므로 이전 출구에 주어진 폭은 줄어들 수 있다. 이 폭과 유량 계수는 실측 강폭·월류식이 아니다.

## 양쪽 최종 수위의 동시 해

각 연결 면의 후보 함수는 다음과 같다.

`Qab = C W [(max(za−zc,0))^1.5 − (max(zb−zc,0))^1.5]`

양수면 a에서 b로, 음수면 b에서 a로 흐른다. 같으면 교환이 0이다. 받는 쪽 수위를 이전 단계 값으로 고정하지 않고 다음 식의 **모든 경계 최종 저장량**을 함께 푼다.

`Vi,new + dt × Σ Qij(Vi,new,Vj,new) = Vi,available`

원본 기둥의 단계별 면적 곡선을 사용한다. 단조 좌표별 근 찾기와 보호된 Newton 반복을 사용하며, 최대 200번의 망 반복 안에 잔차 기준을 만족하지 않으면 결과를 만들지 않고 오류로 종료한다. 비선형 방정식의 잔차와 독립 물수지 잔차를 따로 기록한다. 최종 저장은 실제 면별 송수신 합계에서 다시 계산해 보존한다.

출구가 모든 내부 웅덩이 합류 수위 이상일 때만 이 전체 저장 인출식을 적용한다. 그 이하이면 부분 웅덩이별 배수 구현 전이므로 거부한다. 원본 9곳의 낮은 출구와 D567047의 문턱 이하 접촉을 몰래 적용하지 않는다. 최종 수위가 문턱보다 낮으면 그 경계에서 양의 방류를 할 수 없다.

토양·대수층·눈·융설·증발산은 후속36의 후보 가정을 유지한다. 내부 송수신은 외부 강수에 더하지 않는다. 이번 결합식은 같은 소단계에 수신 저장을 반영하므로 후속37의 한 소단계 전달 지연과 다르다. 실제 유속·하도 손실·이동 시간이나 조석 역류를 구현한 것이 아니다.

어떤 경계라도 원본 지형 상한을 넘으면 초과량을 별도로 보존하고 57경계 전체를 멈춘다. 마지막 초과 소단계는 진단이며, 이후 강수를 만들지 않는다. 100년을 완료했다면 이 후보·입력·해상도 아래 계산 완료를 뜻하며 실제 세밀한 지형과 모든 23,022구간의 해결을 뜻하지 않는다.

```sh
node handoff/restore-inputs.cjs
node integration/natural-world/coupled-water-model/prepare.cjs
# 입력 조각은 이미 커밋되어 있다. 원본 아카이브가 있을 때만 다시 계측:

node --test --test-isolation=none integration/natural-world/coupled-water-model/test.cjs
node integration/natural-world/coupled-water-model/query.cjs reference D221625
node integration/natural-world/coupled-water-model/browser-check.cjs
```

`source.cjs.read/unpack`으로 전체 입력을 검증해서 읽는다. 북부의 혼합 얕은 저장 필드는 이진 NaN으로 구분하고, 실제 네 초기 저장은 별도 `northern[].initial`에 있다. 공개 선택 JSON은 이를 수량 요약으로 구분하며 미계산 값은 null이다. 북부 눈 저장을 전체 눈과 별도 북부 네 저장 합계에 중복 더하지 않는다.

화면·다운로드·CLI는 `view.js.query`를 공유한다. 946경계 모두 `sourceCollected:true`이지만 57곳만 `computed:true`다. 미계산 지역의 `annual`, `localTotals`, `localFinal`, `edges`는 null이다. `component`는 언제나 57경계 결과이며 나머지 889경계의 결과가 아니다. `actual:null`, `automaticAdoption:false`를 유지한다.

기준의 60·120소단계 비교와 민감도 조건의 결과는 REPORT와 validation에 기록한다. 민감도 두 조건의 별도 시간 간격 검증은 하지 않는다. 원본 세계·경제·기후·수계·마스크·구지도·고정 아카이브와 기존 보류·종료 연구는 보존한다.
