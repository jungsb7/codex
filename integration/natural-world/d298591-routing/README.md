# D298591 132격자 조건부 출구 방류 — 후속26

후속25의 다음 목표를 진행하라는 사용자 요청에 따라132원본 기둥에 동적 물수지와 제한된 출구 방류를 연결했다. **실제 물리 해결0구간·23,022구간 미정 유지.** 조건부 방류는 가정 장부 밖으로 이동한 물이며 실제 강폭·유량·해양 도달로 채택하지 않는다.

## 원본 입력과 공간

후속25의 `outlet.candidateDomain`132기둥(기존121+11)을 그대로 쓴다. 원본619격자의 강수·기온·눈·얕은 저장 입력을 사용하며 새 기후를 추정하지 않는다.132곳 모두 기존619계측 자료에 포함된다. 원본 canonical/receiver/entry를 따라 각 원본 격자를 처음 만나는 후보 영역의 진입점으로 한 번씩 배정한다. 새 영역 내부는 원본 고도와 D8 연결로5웅덩이에 분할한다.

5웅덩이의 최고 합류 문턱174.432053m는 원래 출구175.298508m보다 낮다. 따라서 출구 방류가 작동하는 수위에서는 모든 국지 웅덩이가 이미 연결되어 있다. 이 조건을 코드에서 검사한다. 다른 구조에 일반화해 출구와 연결되지 않은 웅덩이의 물을 빼지 않는다.

원래 문턱 체적407.907289km³, 우회 문턱176.24058532714844m의 한쪽 극한 기둥체적467.805425km³다. 후자는 유효 영역의 경계를 검사하기 위한 값이며 그 높이에서 닫힌 저수지가 실제로 존재한다는 뜻이 아니다. 기존 해양·호수 마스크와 원본 수계 그래프는 바꾸지 않는다.

## 장부와 출구 가정

`강수 = 육지 증발산 + 수면 증발 + 외부 지하수 순손실 + 조건부 출구 방류 + Δ미배분 보류 + Δ눈 + Δ얕은 저장 + Δ수면 재고`

눈·얕은 저장은 원본 여섯 번째 주기의 시작값에서 이어간다. 잠긴 칸은 육지 증발산·유출을 끄고 강수·온도식 융설을 수면으로 한 번만 넣는다. 얕은 저장은 잠긴 동안 보존한다. 원본 계산을 세분화한 방식과 외부 지하수 손실의 의미는 [후속24](../d298591-surface/README.md)와 같다.

자유 월류 가정은 `Q=C W max(z−zc,0)^1.5`다. C=1.5(SI), 유효 폭W=100/1000/5000m를 가정한다. 접근 유속을 무시해 수위 상승z−zc를 에너지 수두로 놓는다. 계수1.38/1.71은 별도 민감도다. 형상·유속·조도를 측정하거나 이 행성의 실제 계수를 보정한 것은 아니다.

[USACE HEC-RAS 설명](https://www.hec.usace.army.mil/confluence/rasdocs/ras1dtechref/6.5/modeling-bridges/hydraulic-computations-through-the-bridge/high-flow-computations)의 자유 월류식과 에너지 수두 구분을 참고했다. 같은 설명에서 하류 잠김에 따라 방류가 줄어들고 형상에 맞는 보정이 필요함을 확인했다. 이 작업은 HEC-RAS를 실행하거나 그 전체 잠김·역수위 계산을 재현한 것이 아니다. 문턱보다 높은 하류 수위+0.05/+0.5/+1m는 시작부터 보류한다. 이 보수적인 적용 경계는 실제 잠김 임계값을 추정한 결과가 아니다.

증발0.5/1/2m·년 × 외부 순손실0/0.25m·년 × 초기 재고0/50% × 폭100/1000/5000m의36조건을 최대100년 계산한다. 초기 재고는 원래 문턱 체적의 비율이며 가장 낮은 웅덩이를 통해 채우는 이력을 가정한다. 각 조건의 하류 수위3가정은108보류 조합이다. 원본12기간은 공전 위상이며 지구 달력 월이 아니다.

## 수치 방법과 중단

원본 기둥의 수면적A가 일정한 고도 구간에서 출구만으로 배수할 때 `dH/dt=−CW H^1.5/A`다. 이를 적분한 `H(t)=[H(0)^(-1/2)+CWt/(2A)]^(-2)`를 사용한다. 고도 경계를 지나면 면적을 바꿔 남은 시간을 적분한다. 이 식은 위 가정의 직접 유도이며 실측 보정식이 아니다. 수두0에서 방류0, 문턱 아래 재고는 출구로 제거하지 않는다.

각 하위 단계는 **출구 배수 절반 → 수면 손실 절반 → 젖음 상태 고정 →619격자 진화·공급 → 상한 검사 → 수면 손실 절반 → 출구 배수 절반** 순이다. 기후·손실·배수의 동시 연립해가 아니라 분할 적분이다. 공급 직후 상한을 검사하므로 순간 공급 단계의 경계 민감도가 남는다. 기본30단계/기간과6대표 조건의60/120단계를 비교한다.

우회 상한에 닿는 단계는 시작 저장을 복원하며32번 이분 탐색해 부분 단계로 줄인다. 이 구간은 **분할 적분 안의 수치 중단 시각 범위**이며 실제 홍수 시각의 정확도가 아니다. 상한 직후의 추가 배수·손실을 실행하지 않는다. 경계 기둥체적과 작게 남은 수치 초과분(`heldWaterM3`)을 각각 보존한 뒤 전체 계산을 중단한다. 이후 강수·증발·융설을 임의로 계속 넣거나 실제 해양 방류로 전환하지 않는다.

중단 이후 시계열은 만들지 않는다. 마지막 `annual`은 `complete:false`인 부분 연도일 수 있다. 하류 보류는 `annual:[]`, 시간0, 조건부 순간 방류율null이다. 우회 상한에서도 순간 방류율null이다. 이때 누적 장부의0은 ‘처리한 이동 없음’이며 실제 유량0을 의미하지 않는다.
