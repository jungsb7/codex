# 4단계 생태·지표 상세화

[현재 지도](../index.html) · [결과](REPORT.md) · 검증 (전체 인계 패키지: `validation/final-checks.json`)

현재의 모든 대륙·섬에서 원본 육지·호수 268,857격자를 분류합니다. 원본 지형, 2단계 계절 기후와 잠재 생태대, 3단계 연결 수계를 결합한 **설계 후보**입니다. 지형·수변 환경·잠재 식생·지표 형성 환경은 독립 층으로 저장합니다. 평야가 숲일 수 있으며 습지와 평야를 서로 배타적인 피복률로 합산하지 않습니다.

지도에 **생태·지표 / 평야·산록·구릉 / 범람원·습윤 후보 / 지표 재료 가정** 보기를 추가했습니다. 총18개 보기입니다. 좌표 패널의 ‘이곳의 자연환경’에서 겹치는 조건과 미정 사유를 확인하고 JSON을 저장합니다. ‘기준 → 대륙별 생태·상세 타일 탐색’에 대표14개 타일이 있습니다.

## 생성 기준

- 지형은 원본 고도의 5×5 기복·주변 평균 대비 높이와 3×3 기복·최대 이웃 경사를 사용합니다. 바다·호수 높이를 육상 사면 계산에 섞지 않습니다. 120m 미만 기복과 0.25° 이하 광역 경사를 평탄 후보로, 그중 고도800m 이상을 고원으로 구분합니다. 능선·오목 사면·산록·산지·구릉은 별도 규칙을 씁니다.
- 하천은 같은 하류 경로에서 최대50km까지 검색합니다. 수변 후보는 경로 거리30km 이내·격자 중심 상대고20m 이하로 제한합니다. 다른 분수계의 가까운 강을 가져오지 않습니다. 같은 격자 안에서는 실제 하상 상대고를 알 수 없습니다.
- 범람원 후보는 이 조건에 3×3 기복150m 이하, 광역 경사0.6° 이하, 모형 평균유량30m³/s 이상을 요구합니다. 습지 검토 후보는 기복60m 이하·경사0.15° 이하·12기간 모두5m³/s 이상과 유효한 기후 분류를 추가로 요구합니다. **하상·범람 수위·토성·지하수위가 없어 실제 습지 판정이나 면적은 아닙니다.** 토양의 수분 유지 가능성은 검토할 조건으로 남습니다.
- 기존 잠재 생태대를 유지하며 수변 초본·관목·하천림 가능 환경을 겹칩니다. 한랭·PET 공백·미해결 함몰부에 하천림을 확정하지 않습니다. 기후 임계값 주변은 전이로 표시하고, 서부 사막의 산림 기후 충돌을 별도 경고합니다. 충돌 표시에만 검토 권역을 사용하며 생성 자체는 국경·권역 경계에 의존하지 않습니다.
- 충적·붕적·노출 지표는 **형성 과정 가정**입니다. 암종·토성·토심·배수성은 null과 사유로 남깁니다. 기존 수원 모형의150mm 토양 저장량·침투계수 등을 전 대륙 토성으로 바꾸지 않습니다.
- 기존 호안34격자는 연결 문턱과 원본 일별 호수 수위를 선형 보간하여 12기간 침수 일수를 계산합니다. 현재 모형에서는 모두0일입니다. 이는 모든 현실 호안에 습지가 없다는 뜻이 아닙니다.

모든 임계값·생물 반응·토양 가정과 한계는 `core.js`의 `RULES` 및 `output/ecology.json`에 들어 있습니다. 모형 판단의 확률·신뢰도 숫자는 만들지 않았습니다. 실제 숲·농지·빙설 피복률은 자료가 없으므로 null입니다. 원본 호수의 기준 수면만 수면비1로 기록하며 계절 결빙과 구분합니다.

## 6.5km 타일의 범위

전 세계 임의 좌표에 대해 4×4 분할 타일을 요청 시 생성할 수 있습니다. 타일 하나는 부모8×8셀, 자식32×32셀입니다. 대표14개 타일(14,336표본)을 저장했습니다. 전 세계1,887만 자식 셀을 미리 메모리에 펼치지 않습니다.

이 버전은 **고도 보간·부모 속성 계승 상세층**입니다. 보간은 타일 좌표와 무관한 전역 격자로 계산하며 원본 육해 마스크를 유지합니다. 생태대·수변 후보·기후·수계는 부모에서 계승합니다. 따라서 새로운6.5km 생태 경계나 지류가 해석된 것은 아닙니다. 미세 지형을 유하 고도로 사용하지 않고, 물길 연결·물수지·호수 수위는 상위 모형에 고정합니다. 자식 유량은 null, 부모 계정 ID만 기록하므로16번 합산할 수 없습니다. 구면 면적은 자식16개의 합이 부모 면적과 일치합니다.

상세 유역의 지류·범람원·피복 경계를 실제로 분화하는 것은 이 기본 타일에 경계조건을 추가하는 후속 확장입니다. 25m 전 세계 지형이 완성되었다고 해석하지 않습니다.
