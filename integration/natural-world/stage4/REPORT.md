# 4단계 결과 — 생태·지표 상세화

전 대륙·섬의 육지와 기존 호수268,857격자에 지형·잠재 생태·수변 환경·지표 형성 가정과 미정 사유를 연결했습니다. 지형과 생태가 별도 층이므로 ‘평야 + 온대림 후보 + 범람원 후보’처럼 같은 좌표에 겹쳐 나타납니다. 지도에4개 보기를 추가하여 총18개 보기가 되었고, 좌표 JSON과 대표 타일을 저장할 수 있습니다.

## 전 대륙 분류

| --- | ---: |

| 고원 | 20 |

고도만으로 산지와 평야를 나누지 않았습니다. 원본 주변 기복과 경사, 주변 평균 대비 높이를 함께 사용했습니다. 광역 모형의 부드러운 고도가 평야 비중에 영향을 줍니다. 이 숫자는 실제 산맥·평야의 개수 또는 세부 지형 조사 결과가 아닙니다.

같은 하류 경로의 물길과 낮은 지형이 겹치는 **범람원 검토 후보10,522격자**, 더 평탄하고 연중 모형 흐름이 있는 **하천 습지 검토 후보9,804격자**를 선별했습니다. 두 분류는 표시에서 구분되며 습지 후보도 넓은 의미의 범람 환경에 포함될 수 있습니다. 다른 분수계의 가까운 강을 가져오지 않고, 실제 하상 고도와 범람 수위가 미해상이므로 확인된 습지 면적은 null입니다. 후보 격자의 전체 면적을 실제 습지 면적으로 합산하지 않습니다.

식생은 기존 기후 생태대를 유지하고 **하천림29,561격자**, 계절 하천변 초본·관목79,849격자, 수변 초본·습윤 식생9,726격자의 가능 환경을 겹칩니다. 이 후보는 격자 일부에 있을 수 있는 환경이며 숲·갈대 군락의 위치와 면적을 확정한 것이 아닙니다. 기후 전이70,905격자, 기후·PET 판정 보류29,939격자, 서부 사막과 산림 기후의 충돌2,629격자를 표시합니다.

토양은 입도·암종·토심·배수성의 근거가 없어 수치로 채우지 않았습니다. 하천 퇴적·사면 이동·노출 지표·호소 퇴적 가능 환경만 분류합니다. 미해결 함몰부28,858격자는 내부 물 배분 미정으로 유지하며 강 유입량만으로 숲·습지를 만들지 않습니다. 실제 육상 피복률은268,648격자 모두 null과 사유를 제공합니다. 기존 농지·도시 합계를 임의로 공간 배분하지 않았습니다.

## 호안과 상세 타일

원본 호수 모형의 연결된 호안 후보34격자에 대해 일별 수위와 연결 문턱을 비교하고, 문턱 통과 시점을 선형 보간하여12기간 침수 일수를 계산했습니다. **현재 자료에서는34곳 모두0일**입니다. 모형 수위가 이 광역 격자들의 문턱에 닿지 않으므로 새로운 호안 갈대습지를 지정하지 않았습니다. 격자보다 작은 얕은 호안·계절 습지가 없다는 뜻은 아닙니다. 기존 기준 수면209격자는 그대로 유지합니다.

11개 검토 권역을 포함한 대표14개 타일, 총14,336개 자식 표본을 저장했습니다. 임의 좌표에서도6.5km 간격 타일을 요청 시 생성·저장할 수 있습니다. 원본 육해 마스크·기후·생태·수계 계정을 계승하고 고도만 연속 보간합니다. **새로운6.5km 지류·범람원·피복 경계를 확정한 단계는 아닙니다.** 세부 자연물 경계의 분화는 후속 확장 과제입니다. 전역 자식 격자를 미리 할당하지 않아 메모리 중복을 피합니다.

타일 경계를 넘어도 같은 전역 좌표는 같은 결과를 받습니다. 자식16개의 구면 면적 합은 부모와 같고 유량은 부모 계정 ID만 참조합니다. 보간 지형으로 물길을 다시 계산하거나 물수지를16번 합산하지 않습니다. 생성 규칙은 국경과 검토 권역 경계를 사용하지 않습니다.

## 검증과 보존

수치 검사49개가 통과했습니다. 새로운9개 검사는 전체 분류 범위, 평탄한 고원과 급한 저지의 구분, 습윤 조건, 전 후보의 하류 연결, 독립적인 수위 문턱 통과 사례, 피복·토양 미정 보존, 한랭·공백의 하천림 배제, 타일 면적·계정 보존과 경계를 확인합니다. 기존 수계·기후·기준층·Atlas40개도 통과했습니다.

브라우저 검사21개가 통과했습니다.18개 보기·11개 권역,14개 대표 타일, 좌표·타일 JSON 일치,12기간 호안 표, 설정 충돌 표시, 모바일과 기존 Atlas 진입을 확인했습니다. 원본1,663파일과 이전 통합288파일을 대조하여 예정된 공용 화면·인계 문서14파일 외 변경이 없음을 확인했습니다. 앞 단계 입력·출력·검증과 경제 장부도 동일합니다. 최종 증거는 `validation/final-checks.json`입니다. HTTP 화면 로딩을 검사하며 관리형 브라우저 정책이 차단하는 file:// 직접 열기는 미검증으로 기록합니다.

원본1,663파일, 경제 장부와1~3단계 입력·출력·검증은 보존 대상입니다. 현재 독립 HTML은 약76.2MB로 전 자료를 포함합니다. **이번 자연지리 변경은 GitHub Pages에 배포하지 않았습니다.** 다음은5단계 자연 지도 표현: 배율별 선·질감·기호, 보기 정리, 계절·좌표 패널과 로딩 개선을 진행합니다. 개별 화산·빙하·실제 피복과 수리학적 범람 경계는 자료가 없어 미정입니다.
