# 세부 지형·피복·침수 경계 모델

[세부 지도](index.html) · [결과와 검증](REPORT.md) · [계산 요약](output/summary.json)

후속47은 원본 격자 내부를16×16으로 나누어 지형·침수와 국지 배수 경로를 계산한다. 숲·습지와 맞닿은 인접 격자에는 면적을 보존하는 세부 피복 경계를 만든다. 통합지도 지점 카드의 **이 지점의 세부 경계 보기**로 같은 지점·기간을 연다. 지도와 AI는 같은 `core.js`를 사용한다.

상태는 `conservative-downscaling-scenario`, 버전은 `subgrid-boundaries-v1`이다. 기존 `natural-canon-v1`의 수치·권위·원본 경계를 바꾸지 않는다. 세분 지형은 명시된 가정으로 만든 계산 모델이며 관측 고해상도 DEM이나 새 확정판이라고 부르지 않는다. `actual:null`, `automaticAdoption:false`, `worldReferenceModified:false`를 유지한다.

## 지형

268,857개 원본 육지·호수 격자를 각각256개 등면적 표본으로 나눈다. 총68,827,392표본이며 남북 간격은 대략1.6km다. 경도와 `sin(위도)`를 균등 분할하므로 같은 원본 격자의 작은 칸들은 구면 면적이 같다. 극지방의 각도·거리 간격은 달라진다.

육지 꼭짓점은 주변 원본 육지 고도의 평균을 공유한다. 네 꼭짓점을 이중 선형 보간하고, 격자ID로 고정된4×4 잡음 보간에 `16u(1-u)v(1-v)`를 곱해 내부 기복을 더한다. 기복 계수는 원본 경사(도)의2배, 최소0.5m·최대30m다. 내부 평균 보정항도 같은 함수로 곱해 격자 끝의 공유 고도를 유지하면서 표본 평균을 원본 고도와 일치시킨다. 평균 보정항은 그30m 기복 한계와 별개이며, 원본 고도 차이가 크면 크게 나타날 수 있다.

원본 호수209격자는 평평한 원본 바닥을 그대로 쓴다. 해양은 세분하지 않는다. 숲·습지 경계가 새로운 지형의 물리적 결과로 자동 생성된 것으로 해석하지 않는다. 기존 후속41 계곡 종단을 이 DEM에 일괄 합성한 것도 아니다.

## 피복 경계와 면적

같은 격자가 여러 교환에 겹치지 않도록 인접한 육지 두 개를 짝짓는다. 최소 한쪽이 숲·범람 적응 수림·습지이며, 원본 호수·기준 저류 수면·빙원은 교환에서 제외한다. 10,654쌍,21,308격자가 해당한다. 나머지 경계는 원본을 유지한다.

공유 경계의 두 끝은 고정하고17절점의 굴곡을 만든다. 굴곡은 두 원본 격자의 사각형 합집합 안에 머문다. 내부 절점의 공통 보정량을 풀어, **내보내는 경위도 선분 자체의 구면 면적**이 각 원본 분류 면적과 일치하게 한다. 등면적 좌표에서 보존한 값을 경위도로 단순 변환할 때 생기는 선분 근사 오차도 이 단계에서 보정한다.

구의 반지름은 원본과 같은6,371,000m다. 경계 면적은 경위도 직선의 `R² ∮ sin(위도) d경도`를 해석 적분한다. GeoJSON을 타원체나 다른 선분 해석으로 재측정하면 별도의 차이가 날 수 있다. 이것은 면적 보존형 경계 가정이며 토양·종자 확산·식생 경쟁의 생태 시뮬레이션은 아니다.

## 침수: 같은 저장량을 세분 지형으로 재배치

후속46의 기준100년 끝과101년차12기간 끝, 총13상태의 **각 웅덩이 저장량**을 입력으로 쓴다. 원본3,232웅덩이와 소속 격자는 유지한다. 각 웅덩이에 속한 모든 작은 칸의 바닥을 정렬하고 다음 식을 만족하는 공통 수위를 푼다.

`저장량 = Σ 작은 칸 면적 × max(0, 수위 − 작은 칸 바닥)`

빈 웅덩이는 물이 없으며 조회 수위는null이다. 양수 수량은 깊은 부분에 모이므로 같은 원본 격자 안에서도 젖은 부분과 마른 부분이 구분된다. 수량은 웅덩이 전체에서 보존하며 개별 원본 격자의 저장량은 바뀔 수 있다. 수심1cm 이상을 침수로 집계하고 원본 호수는 육지 침수 면적에서 제외한다.

8×8과16×16을 각각 계산하여 수위·전 세계 침수 면적을 비교한다. 양수 저장량에서 수위 차이1m 초과는 화면과 JSON의 `refinementSensitive`로 표시한다. 이 차이는 공간 표본 간격의 민감도이지 관측 오차나 신뢰 구간이 아니다. 원본 약26km 지형의 불확실성도 없어지지 않는다.

이번 것은 고정된 저장량의 정수압 재배치다. 세분 지형에 따라 기존 연결부 높이·교환·침투·증발을 다시 시간 적분하지 않았다. 내부 장애물로 분리된 물의 이동 경로를2차원 수리학으로 검증하지도 않았다. 따라서 개별 폭풍 홍수, 침수 지속 시간, 새로운 유량은 제공하지 않는다. `duration:null`, `exchangeFeedback:false`다. 기존101년차 시간 계산과 장부는 후속46에서 계속 조회한다.

## 격자 내부 배수 경로

각 원본 육지 격자에서256표본의4방향 연결을 사용한다. 기존 수계의 출구가 바로 옆 격자로 지정되어 있으면 그 출구 방향과 경계의 통과점을 고정한다. 이 조건을 만족하지 않는 격자는 같은 웅덩이의 내부 집수점으로 보낸다. 새로운 격자 밖 출구나 기존 하류 관계를 만들지 않는다.

출구에서 우선순위 침수 알고리즘으로 연결 트리를 만들고 각 표본의 기여 면적을 하류에 누적한다. 표시선은 누적 면적이 `max(1km², 원본 격자 면적의2%)` 이상인 가지다. 지형에 인위적으로 채워야 하는 높이는 별도 진단값이다. 이 채움은 위 침수 계산의 바닥·저장량에 적용하지 않는다. 급경사에서는 큰 채움이 필요하므로 이를 실제 침식 계곡이나 성립이 검증된 소하천으로 읽지 않는다. 개별 배수선의 유량은null이다.

## AI·GIS와 재현

```sh
node integration/natural-world/subgrid-boundaries/query.cjs cell 310879 1
node integration/natural-world/subgrid-boundaries/query.cjs cell 134409 3
node integration/natural-world/subgrid-boundaries/query.cjs geojson 134409 3
node integration/natural-world/subgrid-boundaries/query.cjs series 310879
node integration/natural-world/subgrid-boundaries/query.cjs pond 1535 1
```

기간0은 기준100년 끝,1–12는101년차 기간 끝이다. 지점 JSON에는256개 작은 칸의 좌표·고도·수심, 피복 폴리곤, 배수 트리와 면적, 저장량 보존 진단이 있다. GeoJSON은 겹쳐 읽는 `conserved-cover`, `terrain-subcell`, `local-drainage` 층이므로 모든 도형 면적을 함께 더하지 않는다. 작은 칸의 면적은 원본 면적/256이다.

모델 입력과 코드는 SHA-256으로 고정한다. 브라우저·CLI는 매니페스트의 파일 크기·해시를 검사하고 손상 시 조회·내보내기를 막는다. Node 표준 라이브러리만으로 재현한다. 이전 단계의 build 스크립트를 실행할 필요가 없다.

```sh
node --max-old-space-size=4096 integration/natural-world/subgrid-boundaries/build.cjs
node --test --test-isolation=none integration/natural-world/subgrid-boundaries/test.cjs
node integration/natural-world/subgrid-boundaries/browser-check.cjs
```

build가 끝난 뒤 검사를 실행한다. 브라우저 검사는 이 환경의 Chromium·Playwright 설치 경로를 사용한다. 모든 새 기록은 이 폴더에 두며 기존 모델·연구·정설 자료는 덮어쓰지 않는다.
