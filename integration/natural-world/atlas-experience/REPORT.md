# 통합 자연지도: 계절·자연물 정보·확대 경관

이번 범위인 **12기간 계절 지도, 자연물별 정보창, 전 대륙 확대 경관의 설계 표시층**을 구현했다. 기존 세계의 물리 자료는 유지한다. 표시용 상세화를 실제 고도·수계·식생 확정과 구분한다.

## 계절

통합 지도에 ‘계절’ 보기를 추가했다. 기간 강수량, 기간 기온, 같은 지점의 연중 상대 강수를 전환한다. 이전/다음 버튼·슬라이더·좌표별 12기간 강수 막대를 통해 기간을 바꾼다. 자연환경·식생 보기에서도 계절 기능을 켜면 한랭 강수 및 온대림 저온기 색상과 물길의 기간 유량 표현을 볼 수 있다.

268,857개 원본 격자와 12기간 기온·강수는 기존 자료를 그대로 읽는다. 기후는 4° 원본/채택된 2° 수분 처방의 표본이며, 원본 지형 약26km와 확대 표시 약3.25km를 새 기후 해상도로 해석하지 않는다. 0°는 북향 분점,90°는 북반구 여름,270°는 남반구 여름이며 지구의 달력 월이 아니다. 기온·강수는 위상 표본, 유량은 그 위상부터 다음 위상까지의 기간 평균이다.

상대 강수 색은 해당 격자의 12기간 최소~최대 사이 위치다. 연중 차이가1mm 이하이면 중립색을 쓴다. 건기·우기의 생태학적 확정 분류가 아니다. 한랭 밝기 표현은 기온0°C 이하·강수5mm 이상의 기존 표시 규칙이며 실제 적설량·빙하·결빙 범위를 만들지 않는다. 온대림의5°C/12°C 색 전환은 표현 가정이다.

후보 물길의 굵기는 선택 기간 유량에 반응한다.5m³/s 미만 또는 하류 미정은 점선이다. 구간 선별은 기존 연평균/차수 기준을 유지하여 기간 변경 시 물길이 갑자기 소실되는 것을 피한다. 표시 유량은 기존 로그 양자화값으로 오차≤0.000245×(1+Q)m³/s이며 정밀 수지 장부는 변경하지 않는다. 미정 경계의 유량은 방류 인증이 아니다.

계절을 처음 켤 때 기존 기후27.6MB·수계13.8MB 압축 파일을 읽고 SHA-256과 세계·격자 대응을 검사한다. 브라우저 메모리에서 재사용한다. 실패는 명시적으로 표시하고 재시도할 수 있다. 누락값을 평균·0으로 대체하지 않는다. 선택 기간·색상·계절 사용 여부는 URL과 JSON에 저장된다.

## 자연물 정보창

기존27개 선형 자연물(산계16, 주요 강7, 그 밖의 해구·고개)과 물길 후보45,824구간을 지도에서 클릭할 수 있다. 기존 강·산맥은 목록으로도 선택할 수 있다. 화면상8px 이내의 보이는 선을 선택하며 레이어를 끄면 해당 개체의 강조와 클릭 대상도 숨긴다. 선택 해제·전체 보기·정보 JSON 저장을 지원한다.

기존 설정/계산 후보, 원본 중심선의 의미, 경로가 통과하는 권역과 원본 격자의 고도·기온·강수 범위를 보여 준다. 후보 물길은 기존 집수 면적·상류 합류 구간 수·다음 하류 구간·종착점·기간 유량을 연결한다. 기존 주요 강은 ID가 일치하는 원본 본류 연결 기록을 보여 준다. 산맥에 가상의 유역을 붙이지 않는다. 좌표를 새로 선택하면 이전 자연물 선택은 해제된다.

기후 범위는 개체 중심선 표본의 범위이며 유역 전체 평균이 아니다. 산계 처방 진폭·폭은 실측 최고고도나 확정 경계가 아니다. 실제 강폭·범람 범위는 여전히 미정이다.

## 확대 지형 상세화

모든 대륙의 자연11권역에 같은 결정 규칙을 적용한다. 자연환경·지형·식생 보기에서12배 이상 확대하고 후보·상세화 표시가 켜져 있으면 다음을 생성한다.

- 원본 고도를 육지 표본으로 정규화한 쌍선형 보간으로 연결하고 방향성 음영과500m 간격의 고산 등고선 표현을 추가한다. 새 물리 고도를 저장하거나 수계 계산에 넣지 않는다.
- 기존 물길을 따라 계곡 음영을 배치한다. 물길 후보의 내부 모서리는 짧은 곡선으로 다듬되 각 구간 시작·끝점과 합류 연결은 유지한다. 곡선 표본이 바다·기존 호수에 들어가면 그 모서리는 원래 경로를 유지한다. 실제 새 소하천·침식곡을 확정하지 않는다.
- 기존 숲·습지 후보 내부에 주변 분포와 세계 좌표에 고정된 무늬로 불규칙 가장자리·빈터·습윤 패치를 만든다. 식생 보류 격자는 숲 패치를 억제하며 습지의 수문 보류도 유지한다. 현재 피복 면적이나 침수 경계로 사용하지 않는다.
- 같은 좌표는 이동·확대·다시 열기에서 같은 모양을 만든다. 원본16×16격자 타일을 각 축8분할하고 최대96개 표시 타일을 캐시한다. 명목 남북 표본 간격은 약3.26km다. 해안선·기존 호수의 원본 마스크는 그대로 유지한다.

‘확대 경관 상세화’를 끄면 기존 격자 표현으로 돌아간다. 기존 세계 설정만 보기에서도 새 상세 후보는 숨긴다. 좌표 정보와 JSON은 원본 고도를 유지하며 설계 표시의 해상도·의미를 별도로 제공한다. 전체 대륙의 실제 세부 지형을 새로 확정했다는 뜻은 아니다.

## 검증과 남은 범위

원본 기온·강수 전수 대조, 전 물길 기간값·연결 끝점 검사, 해양/호수 마스크, 보류 후보 억제, 타일 경계 보간, 출처 불일치·실패 복구, 클릭·URL·저장·모바일 동작을 검증한다. 기존 경관 초안·9곳 국지 검토 화면도 회귀검사한다. 상세 결과는 별도 검증 기록에 저장한다.

전역 미정 경계1,184곳·집수권168,576격자·후보 물길23,022구간의 물리 미정은 유지한다. 앞선9곳 국지 검토는 종료 상태다. 이번 세 기능의 구현 완료와 전 대륙 물리 수계의 확정 완료는 구분한다.

실제 GitHub Pages 도메인의 직접 브라우저 검사는 환경 네트워크 정책상 불가능하다. 공개 패키지의 `/codex/` 경로를 로컬 브라우저에서 검사하고 해당 커밋의 Pages build/deploy 결과를 별도로 확인한다.
