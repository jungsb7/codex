# 후속50 결과 — 내부 저류칸과 양방향 교환

365개 민감 웅덩이를17,123개 원본 격자 내부 저류칸으로 나누었다. 전체 계산망은19,990개 저류 단위와65,028개 연결이다. 기존 외부 연결9,858개와 원본 호수 출구를 보존하고,같은 원래 웅덩이 안에55,170개 이웃 연결을 추가했다. 원본·정설v1·앞선 단계 수치는 변경하지 않았다.

**가정한 모형의 구현과 검증을 마쳤다. 전체 공간·시간 수렴이나 모든 자연환경 세부 구현이 완료된 것은 아니다.** 새 결과는101년차 사건 강수 시나리오이며 관측 지형·실제 홍수의 검증 결과가 아니다.

## 실행과 보존

같은 원래 웅덩이의100년 말 물,같은 대상 육지 눈/토양/지하수/이동 저장,같은 기간 강수량을 사용했다. 네 경우 모두12기간을 완주했다.

| 경우 | 최대 연간 상대 물수지 잔차 |
|---|---:|
| 내부 칸,16분할·240단계 | 2.851×10⁻¹² |
| 내부 칸,32분할·120단계 | 4.121×10⁻¹³ |
| 내부 칸,32분할·240단계 | 2.810×10⁻¹² |
| 공통 수면 대조,32분할·240단계 | 1.096×10⁻¹² |

전체 집수권·기간 중 최대 상대 잔차는5.379×10⁻¹²다. 음수 저류나 초과 물량 폐기는 없다. 초기 물의 내부 분배에서 합계 차이는 최대0.000030518m³였으며,선택된 배경 유입의 분배 합계 차이는0이다. 선택된 배경 웅덩이102개,11,186격자의 유입은 원본 격자별 유량에서 복원했다.

각 두 칸 교환은 제한된 암시적 방정식으로 풀고 정순/역순 반 단계로 순회한다. 모든 교환은 부피와float64수위 표현 간격을 반영한 잔차 기준을 통과했다. 최대 절대 방정식 잔차0.0757584m³,최대 표현 허용오차0.0759904m³다. 이는 전체 물수지 잔차와 다른 검사다. 정방향/역방향 누적량은 전체 시간단계의 순교환을 방향별로 합친 값이며,반 단계의 총 통과량은 아니다.

새 연속 곡선 입력을 끈 전체120단계 실행은 후속49의 모든 출력과 **정확히 일치**했다. 원본 격자 평균 높이의 최대 오차는32분할에서2.33×10⁻¹⁰m였다. 선택된 모든 웅덩이에서 한 격자씩,미소 수심을 포함한1,460개 독립 삼각면 적분 대조를 통과했다.

## 공간·시간 차이

- 같은 물을 담은 웅덩이 단위의 새16/32 지형 비교: 최대4.387m,1m 초과10곳. 이10곳의 추가32/64 정적 비교는 최대0.483m였다.64분할은 동적 계산에 사용하지 않았다.
- 예전 공간 비교에서 가장 민감했던 웅덩이1245는 같은 수량에서 새16/32 차이0.912m였다. 예전27.674m는 다른 격자 지형과 동적 수량의 비교이므로 두 수치를 같은 오차 검사의 전후값으로 취급하지 않는다.
- 내부 **개별 격자**의 최소 높이는16/32 사이 최대11.044m 차이였고,2,309격자가1m를 넘었다. 웅덩이 전체 저장곡선의 정적 비교와 다른 범위다.
- 동적 기간 말 수위 차이: 시간120/240 최대 **4.046m**(270020,5기간),공간16/32 최대 **14.574m**(298873,12기간). 두 경우 모두 바닥 위1cm 이상인 비교에서도 이 최대값은 남는다. 시간 분할에 따른 기간 최대 수위 차이는4.100m다.

따라서 모든 지점의 수렴을 선언하지 않는다. 화면에서 공간 차이1m 초과를 표시하고,원시 비교값·동적 수량·이력을 그대로 제공한다. 분할 차이를 관측 신뢰구간으로 부르지 않는다.

## 내부 연결의 효과를 읽는 방법

공통 수면 대조는 각 원래 웅덩이가 하나의 높이를 갖는 경우다. 그 높이는 상류 격자 바닥보다 낮을 수 있다. 내부 칸의 수위와 공통 높이의 단순 최대 차이5,988m를 실제 홍수 높이 변화로 해석하면 안 된다. 두 경우 모두 같은 격자 바닥 위1cm 이상인 대상에서도 최대 차이는280.694m였다(132499,2기간). 가정한 공유 경계의 문턱이 내부 저류를 크게 바꾼다는 결과이며 실제 지형 장벽을 입증한 것이 아니다.

원래 웅덩이별 총저장 비교의 최대 차이는77,360,001,276m³였다(1415,12기간;내부 칸79,714,582,393m³,공통 수면2,354,581,117m³). 공유 모서리 보간과 내부 문턱 가정에 따른 결과다. 실제 하도 절개·침식/퇴적·세분 격자 안의 장애물 연결을 아직 연동하지 않았다. [비교 해석 자료](validation/comparison-interpretation.json)에 조건과 지점을 남겼다.

## 검사·배포

자료·수치 검사22개,새 화면9개와 기존 지도/상태/사건 강수 회귀33개로 브라우저 검사42개를 통과했다. 새 화면의 지점/GIS/물수지/이력 JSON4개 실제 다운로드를 AI 조회와 대조했다.1440/1024/390/320px 표시,뒤로 가기,새로고침,늦은 응답,해시 오류/재시도를 검사하고 데스크톱·모바일 화면을 확인했다. 미세 저장의 수두,빈 칸,장벽,넘침,역류,해양 유입,해석해에 대한 시간 수렴을 별도 검사했다.

공개 결과187,602,813바이트,최대 파일15,575,592바이트다. 모든 세밀/시간 비교 이력의float64 비트를 원래 계산과 전수 대조했다. XOR·바이트 자리 재배열·gzip은 무손실이며 정밀도를 줄이지 않는다.101년 말 모든 대상 육지 저장과 내부 칸 수량도 다음 단계 입력으로 보존했다.

- [자료 검사](validation/model-tests.txt) · [새 브라우저 검사](validation/browser-checks.json)
- [이전 출력 전체 일치](validation/event-identity.json) · [보존 검사](validation/preservation.json)
- [패키지](validation/package.json) · [배포 기록](validation/deployment.json)

중간의 비수렴 실험과 메모리 종료 결과는 배포에서 제외했다.16GiB 환경의 전체 계산은 순차 실행한다. [제외 기록](validation/development-failures.json).

공개 Pages 주소는 이 환경의 네트워크 허용 목록 밖이다. 직접 HTTP 검증을 우회하지 않으며,로컬 브라우저 검사와 GitHub Pages 작업 결과를 구분해 배포 기록에 남긴다.

## 남은 작업

대상 밖 웅덩이 내부 세분,각 원본 칸 안의 연결/2차원 운동량,공간·시간 민감도는 여전히 한계다. 이번 단계 뒤의 기존 순서는 빙설/동토→개별 물길/침식·퇴적→피복/생태→지정 지하 통로 압력과 전체 결합이다. 최소 구현과 종료 기준은 [유한한 완료 기준](../../../handoff/MODEL_COMPLETION_CRITERIA.md)에 정리했다. `allRequestedDetailImplemented=false`를 유지한다.

## 게시 전송 포장 검증

GitHub 연결 도구의16MiB 요청 본문 제한으로 기간gzip을9,000,000바이트 이하 조각으로 나눴다. 원래 압축 바이트·SHA-256은 모두 동일하며,계산 결과를 다시 계산하거나 정밀도를 낮추지 않았다. CLI/브라우저는 각 조각과 합친gzip의 길이·해시를 모두 확인한다. 물리파일 최대9,000,000바이트,재조립한 자료 최대15,575,592바이트. `validation/transport-packaging.json`과포장후자료/브라우저검사를참조한다.
