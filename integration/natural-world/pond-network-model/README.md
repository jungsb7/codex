# 23,022구간 전체의 저류·침투·넘침 후보

기존 모델은 보류 수신 유역에 물이 닿거나 집수권 안의 여러 낮은 웅덩이를 하나로 표현할 수 없으면 멈췄다. 이번 후보는 원래 1,184경계·23,022구간을 모두 포함하고, 원본 지형의 3,232웅덩이와 9,858연결에서 양쪽 수위를 함께 푼다. 과거 보류 235경계와 D298591 관련 3경계도 사용자의 전체 해결 진행 지시에 따라 **새 후보 안에 포함**한다. 과거 연구의 보류·중단 기록을 수정한 것은 아니다.

[화면](index.html) · [계산 결과](REPORT.md) · [요약](output/summary.json) · [출력 해시](output/manifest.json)

완료 기준은 세 조건 각각 100년 동안 모든 대상 집수권의 물을 저장·증발·침투·복귀·전달에 배정하고 연간 및 누적 장부를 맞추는 것이다. 이는 명시한 가정에서의 후보 계산 완료다. `actual:null`, `automaticAdoption:false`를 유지한다. 원본 세계·경제·기후·수계·해양/호수 마스크·구지도와 별도 아카이브를 변경하지 않는다.

## 지형과 연결

- 대상 원본 육지 168,576격자를 원래 경계 안에서 단조 하강하는 웅덩이로 나눈다. 같은 높이의 평탄지는 결정론적 출구와 순환 없는 연결을 쓴다. 경계나 높이를 깎지 않는다.
- 나머지 육지 100,072격자는 원본 계절별 **지역 유출**을 외부 공급량으로 받는다. 강수를 다시 더하지 않는다. 이 공급의 연간 합은 약 11.523조 m³다.
- 원본 호수의 243개 바닥/강둑 기둥, 초기 물 약 2.058조 m³, 계절 증발, 문턱 420m·폭 350m·계수 1.7의 기존 해양 출구 경로를 보존한다. 육지인 강둑 34개는 호수 기둥에만 들어간다. 전체 표면 기둥은 중복 없이 268,857개다.
- 서로 접한 웅덩이 쌍마다 실제 원본 D8 인접 면 중 가장 낮은 문턱을 쓴다. 모든 높은 면을 별도 수로로 더하지 않는다. 유효 폭은 원본 격자 간격의 2%, 계수 1.5라는 설계 가정이다. 실측 하폭이 아니다.
- 저장량은 원본 높이와 면적으로 만든 조각별 선형 수위–부피 곡선이다. 과거의 문턱 위 5m 상한을 없앴다. 물이 높아지면 연결된 다른 웅덩이와 교환하며, 초과량을 버리거나 보류 유역을 무한 배수구로 취급하지 않는다.
- 바다는 수위 0m의 외부 경계다. 실제 원본 해안 면에서 양방향 전달을 계산하고 바다 유입과 방류를 장부에 각각 적는다. 그래프상 모든 웅덩이는 바다까지 연결되지만, 모든 웅덩이에서 실제 방류가 발생한다는 뜻은 아니다.

## 기후·저장·수치 계산

기존 공개 117,320격자 입력 23,484,677바이트를 그대로 재사용한다. 부족했던 51,256격자만 같은 원본 시뮬레이터에서 추가 관측했다(9,835,947바이트/17조각). 원본 전세계 유출 비트와 물수지는 수집 전후 동일하다. 북부 총 6,525격자의 눈·토양·지하수·이동 저장은 따로 보존한다. 그 밖의 원본 혼합 저장은 유한 토양/대수층으로 배정하고 남은 물을 표면 저장에 넣는다.

원본 12계절 강수·기온을 365일 연도로 반복한다. 기본 토양 200mm, 대수층 1000mm, 침투 능력 1200mm/년, 토양 배수 시간 0.25년, 지하수 복귀 2년, 표면 증발 0.5m/년이다. 침투 300mm/년과 복귀 8년 조건도 각각 실행한다. 북부는 기존 네 저장 모델(토양 상한 150mm, 기존 침투 비율·배수·복귀·이동 시간)을 결합하며, 북부 지하수에 새 1000mm 상한을 소급 적용하지 않는다. 북부 초기 상태는 원본 60번째 해 시작, 다른 격자는 원본 6번째 해 시작으로 각각 계측했다. 자세한 값은 [scenarios.json](scenarios.json)에 있다.

각 계절을 60단계로 나누며, 표면 연결은 후진 오일러와 전체 웅덩이 반복 해법으로 양쪽 수위를 동시에 푼다. 유량은 `C W ((hA-z)+^1.5 - (hB-z)+^1.5)`다. 실제 면 전달을 한 번 계산하여 양쪽 재고에 같은 양으로 반영한다. 음수·비유한 저장 또는 허용치를 넘은 장부 잔차는 실패다. 기준 조건 120단계 재계산은 100년 누적 바다 방류/유입의 1% 차이 기준을 검사한다. 개별 경계 저장·방류 차이도 공개하며 모든 상태 또는 다른 두 조건까지 수렴했다고 주장하지 않는다.

침투는 노출된 토양으로 들어오는 액체 강수·융설에 적용한다. 잠긴 격자의 새 액체 물은 표면 저장으로 보내고, 수면 아래 추가 저면 침투는 0으로 가정한다. 기존 토양 배수와 지하수 복귀는 계속된다. 저면 침투율을 실측했다고 주장하지 않는다.

각 대상 격자의 액체 유출은 해당 작은 웅덩이에 즉시 들어간다는 집수권 근사다. **23,022개의 원래 구간 ID는 계산된 집수권에 모두 연결되지만, 각 구간의 세밀한 하도 경로·개별 유량을 계산한 것은 아니다.** 원본 격자 내 잠재 젖음 면적/수심은 지형 기반 후보다. 실제 미세 침수 경계, 습지·숲 경계, 강폭, 적설 깊이·빙하 이동·결빙·열수지는 확정하지 않는다. 과거 108보류·14중단 연구의 결론도 그대로다.

## AI 조회와 재현

화면 다운로드와 CLI는 같은 `view.js` 조회 함수를 사용한다. 입력·출력 해시를 검증한 뒤 후보/원본 상태, 모든 가정, 물수지, 개별 웅덩이와 전달량을 돌려준다.

```sh
node integration/natural-world/pond-network-model/query.cjs reference D126467
node integration/natural-world/pond-network-model/query.cjs low-infiltration --reach ORIGINAL_REACH_ID
node integration/natural-world/pond-network-model/query.cjs reference --cell ORIGINAL_CELL_ID
```

원래 구간 ID는 `output/review.json.gz`의 `reaches`에서 확인한다. 대상 격자의 마지막 눈·토양·지하수·이동 저장과 연간 1,186소유자(대상 1,184+배경+호수) 장부는 별도 압축 파일로 공개한다. 화면에는 3조건, 추가 세분화 결과는 검증용 파일에 있다.

```sh
node handoff/restore-inputs.cjs
node integration/natural-world/pond-network-model/compile.cjs /official/node/include/node /tmp/pond-network.node
WATER_NATIVE=/tmp/pond-network.node node integration/natural-world/pond-network-model/build.cjs
WATER_NATIVE=/tmp/pond-network.node node --test --test-isolation=none integration/natural-world/pond-network-model/test-engine.cjs integration/natural-world/pond-network-model/test-data.cjs
node integration/natural-world/pond-network-model/browser-check.cjs
```

전체 재계산은 C++17 컴파일러, 실행 Node와 호환되는 공식 헤더, 메모리와 시간이 필요하다. 네이티브 바이너리는 게시하지 않는다. 작은 계의 독립 JS 기준 해법은 `reference.cjs`다. 웹/AI 조회는 컴파일 없이 게시된 결과를 읽는다. `prepare.cjs`는 원본 지형, `collect.cjs`와 `background.cjs`는 별도 공개 원본 아카이브에서 계측을 재생성하는 개발 도구다. 일상 조회에 이 재수집은 필요 없다.

출력 provenance는 원본 해시, 기존/추가 입력 해시, 실행 코드와 네이티브 바이너리 해시를 기록한다. 환경 경로는 복제 위치로 바꿀 수 있지만 원본 해시는 같아야 한다. 공개 원본은 `handoff/FULL_ARCHIVE.md`의 고정 아카이브 커밋을 사용하며 main에 합치지 않는다.
