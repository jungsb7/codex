# 왕국·제국 전 권역 세부 지형 결과

9개 경제 권역의 모든 원본 격자 안에서 좌표별 세부 높이·경사·사면 방향과 주변 상대 높이를 조회하는 모형을 구현했다. 지도 클릭·좌표 입력·인접 격자 이동·단면·원본 보간면과 비교·수치 JSON 내보내기를 제공한다. 지도 음영에만 사용되는 무늬가 아니라 브라우저와 CLI가 함께 조회하는 수치 높이장이다.

**추가된 세부 형태는 고정 규칙으로 생성한 설계 지형이다.** 원본에 없었던 측량 자료를 발견하거나 지형의 정확도를 검증한 결과는 아니다. 원본 세계·해안/호수 마스크·하천선·국경·인구·농지·식량·수송 계산을 보존했다. 원본 앱에 자동 채택하지 않고 별도의 지형 조회 화면을 제공한다.

남은 209개는 기존 호수 셀로, 세부 하저 고도를 null로 유지한다. 모든 육지 부모 격자 중심에서 새 높이와 원본 고도 차이는 **0m**였다. 내부 시험 좌표의 추가 기복 절댓값은 최대 약 **77.1m**였다. 이는 시험 지점의 최대이며 전체 연속 지형의 전역 극값을 탐색했다는 뜻이 아니다.

전체 128분할 타일을 미리 모두 저장하지 않는다. 모든 대상 좌표에서 동일 규칙으로 지형을 생성하고 요청한 타일만 내보낸다. 권역당 예시 타일 1개씩, 총 9개를 저장했다. 128분할 간격은 남북 약 204m, 동서 약 131~186m이며 한 타일에는 공유 경계 포함 16,641개 꼭짓점이 있다. 작은 표시 간격이 측량 정확도를 의미하지 않는다.

## 지형 생성 규칙

1. 원본 1536×768 고도 격자와 기존 9권역 소유 셀, 수면 마스크, 하천 벡터를 입력으로 사용한다. 원본 기준점을 C1 연속 smoothstep 보간으로 연결한다. 각 기준점 고도는 정확히 고정한다. 원본 고도를 셀 평균으로 재해석하거나 토공 부피를 보존한다고 가정하지 않는다.
2. 주변 3×3 원본 육지 고도의 범위를 이용해 진폭 상한 `clamp(12 + 기복×0.12, 12, 180)m`를 정한다. 낮은 지대에서는 추가로 진폭을 줄여 음의 육지 고도를 만들지 않는다. 진폭 계수는 지질 자료에서 보정한 값이 아닌 명시 설계값이다.
3. 위도 40° 기준 등거리 원통 좌표에서 6km·2.2km·0.8km 규모의 연속 잡음장을 고정 시드 107077로 생성한다. 가중치는 0.5·0.33·0.17이다. 부모 격자 기준점에서 기복이 정확히 0이 되는 매끄러운 함수를 곱한다. 국가별로 독립 난수를 뽑지 않으므로 내부 국경과 타일 경계에서 높이가 끊기지 않는다.
4. 기존 수면과 대상 영역 바깥 셀 경계에서 2km에 걸쳐 추가 기복을 0으로 줄인다. 하천 중심선 반경 약 500m에서는 추가 기복을 0으로 두고 약 3km까지 완화한다. 하천 거리와 잡음 규모는 위도 40° 기준 투영의 근사 거리이며 새 정밀 하천 측량이 아니다. 하천선을 유지하는 것이 배수 연결이나 수심을 보장하지 않는다.
5. 경사는 좌표 동서·남북 ±100m의 수치 고도로 계산한다. 사면 방향은 내리막 방위각이다. 주변 1km 네 방향 평균과의 높이 차이가 ±12m를 넘으면 능선/골짜기 후보로 분류한다. 나머지는 경사 2°·8°·20° 기준으로 구분한다. 분류는 형태 지표이며 토양·경작·통행 적합성 등급이 아니다. 수면·범위 경계를 가로지르면 필요한 경사·상대 높이는 null이다.

## 검증

- 계산 검사 **14개 통과**: 전 원본 중심 고도 보존, 수면 처리, 권역별 타일 재현, 입력 불변, 실행 순서 독립, 인접 타일 공통 꼭짓점 일치, 분할 수준 간 일치, 국가 경계 연속성, 진폭·비음수 제약, 하천·해안 억제, 시드 분리, 잘못된 입력 거부와 메타데이터.
- 브라우저 검사 **12개 통과**: 9권역 선택, CLI 수치 대조, 임의 좌표, 높이/경사/추가 기복 표시, 지도 클릭과 주소 복원, 격자 이동, 두 종류 JSON 다운로드, 수면/범위 밖 처리, 링크, 데스크톱·390px 화면, 브라우저 오류 없음.
- 브라우저와 Node의 부동소수점 연산에 극미세한 차이가 있어 수치 비교에는 절대 1e−8 또는 상대 1e−12 중 큰 허용오차를 적용했다. 같은 Node 실행기에서 저장 예시 타일은 완전히 동일하게 재현된다. 이는 모형 재현 검증이지 지형 정확도 오차가 아니다.
- 원본 파일 1,663개와 이전 통합·계절 결과의 해시를 확인한다. 최종 확인 수치와 파일은 `validation/final-checks.json`에 기록한다. 이전 단계 테스트 전체를 재실행했다고 주장하지 않는다.

## 남은 한계와 연결

기존 분지·하류의 별도 상세 모형은 원본 앱에서 보존된다. 이번 전역 설계층과 그 별도 하상·시설 설계를 하나의 동일 DEM으로 병합하지 않았다. 해당 영역에서 토목·배수 검토를 할 때 이번 지형을 기존 상세 설계의 대체값으로 쓰지 않는다.

해안선과 수면 구분은 여전히 원본 격자 해상도다. 새 소하천, 침식에 따른 지형 발달, 골짜기 출구와 물 흐름의 연결, 절벽·지질·토양·지하수·범람원·계절 수면은 검증하지 않았다. 기후는 기존 4°/12계절 체계를 유지하며 세부 지형에 따른 미기후를 새로 계산하지 않는다.

새 경사 값을 농지 면적·수확량·도로 속도·댐·수로·홍수 계산에 자동으로 반영하지 않았다. 다음 연결 작업은 용도별 규칙과 기존 결과 대비 영향을 명시해 별도로 검증해야 한다. 새 지형의 모든 좌표 조회는 완료했으며, 물리적으로 일관된 고해상도 수문·지질·경제 통합까지 완료한 상태는 아니다.
