# Planet Atlas · 전략 지도 인터페이스

[새 시뮬레이터 화면 열기](index.html)

기존 v0.107 세계와 9개 권역 계산을 지도 중심 화면으로 재구성했다. 남색·황동색 패널, 지형 음영, 국가색, 기존 수도와 하천을 사용한다. 국경·지명·인구·생산량을 새로 만들지 않는다.

## 한 지도에서 확대 탐색하기

지도 위의 **광역 / 권역 / 격자 / 정밀** 버튼을 사용한다. 광역은 전체 9개 권역, 권역은 선택 생활권, 격자와 정밀은 마지막으로 선택한 좌표를 중심으로 이동한다. 정밀 버튼은 지형 모드로 전환한다. 오른쪽 **이 좌표를 지도에서 정밀 확대**도 같은 기능이다. 기존 별도 상세 지형 화면은 아래 링크로 계속 열 수 있다.

- 휠·핀치·+/− 확대를 이어가면 원본 격자가 커지고 지형 모드에서 설계 지형이 표시된다. 원본 셀의 남북 화면 크기 18px부터 격자 단계, 120px부터 정밀 단계다. 최대 확대율은 기존 광역 보기의 6,000배다.
- 정밀 버튼은 남북 표시 간격 약 25m를 목표로 맞춘다. 이후 확대·축소나 창 크기에 따라 표시 간격이 달라진다. 화면에 남북·동서 간격을 따로 표시한다. 축척은 화면 중심 위도의 동서 거리다.
- 정밀 고도 색상은 **현재 화면 내 범위**에 맞춘다. 범례의 최저·최고를 확인해야 다른 장소와 비교할 수 있다. 음영은 기복을 강조하며 높이 값 자체는 바꾸지 않는다. 다른 지도 모드의 색상 범위는 기존대로다.
- 표시 설정에서 확대 시 원본 격자 경계를 끌 수 있다. 격자선은 원본 0.234375° 셀 경계이며 정밀 표본 간격과 다르다. 정밀 지형에서는 지역명 대신 좌표를 직접 선택한다.
- 기후·인구·식량은 확대해도 권역 집계다. 수면과 9개 권역 밖에는 상세 높이를 만들어 넣지 않는다. 원본 지도 위에 투명하게 남기며 미정으로 안내한다.

정밀 지도는 기존 `terrain-v2/core.js`의 같은 좌표 함수를 사용한다. 현재 화면만 최대 320×240 표본으로 계산하며 전 지역의 25m 격자를 한꺼번에 저장하지 않는다. 별도 Worker에서 계산하고 이동 중의 오래된 요청은 취소한다. 갱신 중에는 이전 지형을 원래 좌표에 표시하고 상태를 알린다. Worker를 쓸 수 없으면 원본 지도와 실패 안내를 표시하며 **정밀** 버튼으로 재시도한다.

## 설정을 바꿔 재계산하기

오른쪽 **설정 실험**을 열고 값을 바꾼 뒤 **재계산 적용**을 누른다. 브라우저의 별도 계산 작업에서 9개 권역의 4년·48기간을 실행하고, 성공한 결과로 지도와 지역 패널을 함께 갱신한다. 외부 서버나 API는 사용하지 않는다.

- 왕국 A–E: 지역별 초기 식용 비축 0–365일, 곡물·콩 수량 75–150%.
- 제국 분지·하류·해안: 생활권별 곡물·콩 수량 75–150%. 변경은 배정 작물 농지가 없어 조절하지 않는다.
- 제국 공통: 초기 곡물 비축 50–200%, 기존 상류/하류 노선 수레 각각 0–5,000대, 공유 역축 0–20,000 LU, 초기 운송 조사료 0–200,000t.
- 4년 차 흉작: 기존 작물·목초·어획 감소와 제국 신규 장거리 출발 중단을 적용한다.

비교 기준은 **왕국 초기 비축 180일 + 제국 기존 조건**(`w180-normal`)이다. 기존 `baseline`의 왕국 계절 미확인 값을 임의로 채운 것이 아니다. 새 결과는 `내 설정 · 재계산`으로 따로 표시한다. **지도에 증감 표시**를 켜면 생산·부족·비축 지도에 같은 연도·기간의 `내 설정 − 비교 기준`을 표시한다. 생산 변화의 단위는 퍼센트포인트, 부족·비축은 t다. 증감 색은 감소/증가 방향이며 모든 지표에 일률적인 좋음/나쁨 판정은 하지 않는다.

입력 초기화는 편집값만 기본값으로 되돌리며, 적용하려면 재계산을 누른다. 계절 기준안 보기/내 계산 결과 보기로 결과를 전환할 수 있다. 설정 파일 저장·불러오기와 새로고침 후 재계산을 지원한다. 계산 실패·취소 시 마지막 성공 결과를 유지한다. 지도 주소만으로 실험 설정까지 공유되지 않으므로 설정 파일을 함께 전달한다.

수량은 기존 농지에서의 조건부 민감도다. 종자·사료·저장·수송 손실과 공유 역축·노동을 기존 순서로 재계산한다. 수레만 늘려도 역축·사료가 부족하면 수송이 늘지 않을 수 있다. 농지·물 배정·새 수송로·추가 수확 노동 능력을 인증하지 않는다. 제국 초기 재고는 기존 인구 비례 배분과 시범지역 초기 재고 공제 규칙을 따른다. 왕국 간 교역은 이 실험에서 꺼져 있다.

## 사용

- 왼쪽의 정치 / 생활권 / 지형 / 강수 / 기온 / 인구 / 생산 / 부족 / 비축 버튼으로 지도를 전환한다. 키보드 1–9도 사용할 수 있다.
- 드래그·방향키로 이동하고 휠·+/−·화면 버튼으로 확대한다. 터치 드래그와 두 손가락 확대를 지원한다. Home 또는 전체 보기 버튼으로 돌아온다.
- 지도의 권역·이름·범례, 오른쪽 권역 목록 또는 `/` 검색으로 지역을 선택한다. 검색 결과를 선택하면 해당 지역을 확대한다.
- 지도 배경의 좌표를 클릭하면 같은 좌표의 상세 고도·경사·거칠기를 오른쪽에서 조회한다. `25m 정밀 지형` 링크는 해당 좌표를 그대로 연다.
- 하단의 12개 비교 설정, 1–4년 차, 연간/12기간을 바꾸면 식량·부족·비축 결과가 같이 바뀐다. 재생 버튼은 **저장된 기간별 결과**를 순서대로 탐색한다.
- 표시 설정에서 경계·하천·이름/수도·음영·원본 격자를 켜고 끈다. 현재 보기는 주소와 로컬 저장소에 보존된다. 도움말의 주소 복사로 공유할 수 있다. 파일을 다른 컴퓨터에 옮겼다면 같은 상대 경로에서 주소의 `#` 뒤 보기 값을 사용한다.
- 자료 저장은 선택 권역·현재 장부·좌표 지형·출처 해시를 JSON으로 내보낸다. 모바일에서는 도움말 안의 자료 저장 버튼을 사용한다.

모바일에서는 가로 스크롤 가능한 지도 모드 아래 지도, 비교 설정, 권역 패널 순서로 배치한다. 별도 서버·외부 지도 API·온라인 글꼴은 필요 없다. 브라우저가 로컬 HTML을 차단하면 패키지 루트에서 `python3 -m http.server 8000`을 실행한 후 `http://localhost:8000/integration/atlas/index.html`을 연다.

## 지도 값의 의미

| 모드 | 색상과 범위 |
| --- | --- |
| 정치 | 원본 소유 격자의 6개 국가. 제국의 네 생활권은 같은 국가색 |
| 생활권 | 기존 경제 집계 9개 권역. 제국 생활권은 새로운 행정 국경이 아님 |
| 지형 | 광역 원본 고도와 확대 시 설계 지형·음영. 오른쪽 큰 값은 육지 원본 격자 평균; 클릭 좌표 값은 2차 설계 지형 |
| 강수 | 합성 기후의 권역 평균 연 강수량. 권역 내부의 강수 분포 아님 |
| 기온 | 합성 기후의 권역 평균 최한기 또는 최난기 기온. 기간별 실제 날씨 아님 |
| 인구 | 설정 인구 / 권역 전체 면적. 실제 정착지 밀도 지도 아님 |
| 생산 | 선택 기간의 생산 열량 / 수요 열량. 소비나 실제 공급률 아님 |
| 부족 | 선택 기간 공급 후 부족, t 곡물환산 |
| 비축 | 선택 기간 말의 곡물 재고, t |

사선은 미확인, 어두운 육지는 집계 범위 밖이다. 수면에는 경제 색상 대신 수면색을 유지한다. 정밀 지형을 제외한 색상 범위는 비교하기 쉽도록 모드별 고정하며 상한 초과는 가장 진한 색으로 표시한다. 지역 패널에는 실제 수치를 보여준다. 밝은 테두리는 선택한 생활권이다. 표시한 다이아몬드는 원본에 있는 수도다.

기준안의 왕국 계절 공급·비축은 미확인으로 유지했다. 초기 비축 0/90/180일 등의 추가 비교안은 실제 비축을 인증하지 않는 미채택 가정이다. 지도 모드 선택은 수치 모형의 입력을 변경하지 않는다. `설정 실험`은 위에 명시한 입력을 직접 재계산한다. 더 넓은 원본 앱 설정은 패널 아래 `기존 시뮬레이터의 계산 설정`에서 수행하며, 그 별도 앱의 수정 결과를 이 지도에 자동 수신하지 않는다.

## 출처와 재현

`inputs/sources.json`은 세계·계산·기후·지형 소스의 SHA-256을 기록한다. 빌드는 입력의 세계/경계 해시가 일치해야 실행된다.

- `integration/output/result.json`: 기존 기준·흉작·기후/토질 비교 3개
- `integration/seasonal/output/joint-result.json`: 왕국 계절 비교 9개와 제국 장부
- `application/validation/climate-soil/summary.json`: 9개 권역 광역 기후 평균
- `application/validation/world-map/world-map.json`: 원본 수도·국가 역할
- `integration/terrain/inputs/model.json`: 원본 높이·소유·수면·하천
- `integration/terrain/core.js`, `integration/terrain-v2/core.js`: 좌표별 정밀 지형 조회

패키지 루트에서 Node 24와 Python 3으로 실행한다.

```sh
node integration/atlas/tools/build.cjs
node --test --test-isolation=none integration/atlas/test.cjs > integration/atlas/validation/tests.txt
node integration/atlas/tools/browser-check.cjs
```

브라우저 검사는 Playwright와 Chromium이 필요하다. `PLAYWRIGHT_MODULE`로 설치 위치를 지정할 수 있다. 이 환경에서는 `/opt/codex/cua_node/lib/node_modules/playwright`, `/usr/bin/chromium`을 사용했다. 기존 지도 검사는 계산 10개와 브라우저 13개다. 최신 전체 검증 결과는 `validation/zoom-final-checks.json`에 기록한다. 터치 제스처 구현은 포함하지만 실제 휴대전화 하드웨어 검증은 수행하지 않았다.

재계산 모형은 `live/engine.cjs`와 브라우저 Worker가 공유한다. `live/western.cjs`는 기존 왕국 계절 모형에 지역별 수량·초기 재고를, `live/imperial.cjs`는 기존 제국 모형에 작기 그룹별 수량 계수를 추가한 별도 확장이다. 원본 모형은 수정하지 않았다. 입력 해시와 실행 설정을 내보내기에 기록한다. 기준값의 재현 비교 허용오차는 절대 1e-6 또는 상대 1e-12 중 큰 값이다.

```sh
node integration/atlas/live/run.cjs --defaults /tmp/planet-settings.json
node integration/atlas/live/run.cjs /tmp/planet-settings.json /tmp/planet-result.json
node --test --test-isolation=none integration/atlas/live/test.cjs > integration/atlas/validation/live-tests.txt
node integration/atlas/live/browser-check.cjs
```

재계산 검사는 계산 11개와 브라우저 10개다. 확대 탐색 검사는 좌표·표본·미확인·음영·요청 취소 7개와 실제 Worker·9권역·픽셀 일치·확대 좌표·복원·집계 의미·범위 밖·모바일·실패 복구 브라우저 10개다. 전체 61개 검사를 통과했다.

```sh
node --test --test-isolation=none integration/atlas/zoom/test.cjs > integration/atlas/validation/zoom-tests.txt
node integration/atlas/zoom/browser-check.cjs
python3 integration/atlas/zoom/finalize.py
```

현재 최종 검증·패키징은 `zoom/finalize.py`를 사용한다. `tools/finalize.py`와 `live/finalize.py`는 이전 단계 상태와 산출물을 기록하므로 최신 패키지 생성에 사용하지 않는다. 검사는 원본 1,663개 파일, 기존 비지도 통합 자료와 재계산 엔진의 보존, 3개 브라우저 검사에서 사용한 HTML 해시의 일치를 확인한다.

원본 `application/` 및 이전 계산 결과는 유지한다. ZIP의 `integration/` 폴더를 기존 전체 인계 폴더에 병합하고 `START_SIMULATOR.html`을 열면 새 화면으로 시작한다. ZIP은 기존 원본 앱 전체를 중복 포함하지 않는 업데이트다. 원격 사이트는 배포하지 않았다.
