`site/`는 후보 파일만 원본을 가리키는 임시 심볼릭 링크 트리다. 원본은 바꾸지 않았고 포함된1,959파일의 Git blob 해시가 HEAD와 모두 동일함을 확인했다. 바이트 합계는 압축된 전송량이 아닌 후보 파일 길이 합계다.

- network-water-model11검사/12다운로드, coupled-water-model11검사/9다운로드, 최신 pressure-coupling10검사/4다운로드 통과. 결과·선택·재시도·지도 연결·AI 값 일치를 확인했다.
