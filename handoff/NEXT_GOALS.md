# 다음 작업: 남은 사건별 입력과 세부 물리 검증

후속48에서 [세분 지형 수문 연동](../integration/natural-world/subgrid-hydrology/README.md)을 구현했다. 후속47의 고정 저장량 침수와 별도로 새 저장 곡선·출구·침수 비율을101년차 침투/증발/교환에 반영하고 작은 격자의 침수 지속을 계산한다. [결과](../integration/natural-world/subgrid-hydrology/REPORT.md)와 [배포](../integration/natural-world/subgrid-hydrology/validation/deployment.json)를 확인한 뒤 이어간다.

순서대로 남은 작업:

1. **사건별 강수 입력과 반응 검사.** 원본12기간 기후의 한계가 현재 명확하다. 동일 기간 총강수량을 보존하는 명시적 폭풍 분배 시나리오를 별도로 정의하고, 초기 상태·대조군을 고정하여 사건별 최대 수위/침수 지속/장부 및 시간 간격 민감도를 비교한다. 실제 관측 폭풍이나 확률적 재현기간으로 부르지 않는다. 먼저 입력·대조·보존 검증을 통과한 뒤 지도/AI와 배포를 연결한다.
2. **지형 가정의 공간 민감도와 내부 연결.**8/16수위 차이는 최대27.674m,기간당 최대328웅덩이에서1m를 넘는다. 부분 침수와 토양/눈 평균 상태의 한계를 검토하고, 웅덩이 내부 장애물 연결/2차원 흐름은 별도 해법으로 구현한다. 후속47배수 연결용 최대1,648m 채움을 실제 지형으로 적용하지 않는다.
3. **빙하 이동·장기 평형과 결빙-유량-침수 피드백.** 기존 이동0 규칙은 동역학 해법이 아니며 이번 재침투율에는 동토/결빙 토양 억제를 추가하지 않았다.
4. **국지 물길 유량·침식/퇴적, 식생/토양과 생태 변화, 나머지 피복 경계.** 기존 국지 배수선은 면적 누적 경로이며 개별 물길 유량은null이다. 집수권 장부와 개별 유량을 혼동하지 않는다.
5. **지하 통로 압력·손실수두와 모든 계의 결합.** 개별 화산 위치는 별도 설정이다.

사용자는 이번 단계가 끝난 뒤 기존 요구·계획의 남은 일을 순서대로 계속 진행하라고 지시했다. 각 단계의 결과·검증을 확인한 뒤 다음 단계로 진행하고, 새 범위·비용·별도 승인 필요한 변경은 보고한다. 현재 단계를 중복 실행하거나 기록의 명칭만 바꿔 완료 처리하지 않는다.
