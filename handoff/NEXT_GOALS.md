# 다음 작업: 아직 남은 구체적인 구현

사용자가 “여전히 미정인 것들이 많은 거 같은데”라고 지적했다. 후속44의 **기준 설정 채택**은 유지하지만, 이를 원래 네 항목의 모든 상세 요구가 끝났다는 뜻으로 설명하지 않는다. [후속45 범위 목록](../integration/natural-world/natural-status/index.html)과 [검증·조회](../integration/natural-world/natural-status/README.md)를 읽는다.

현재 실제로 남은 구현:

1. 원본 약26km 격자 내부의 미세 숲 가장자리·습지·지류 경계. 500m 경로 표본 간격은 지형의 관측 해상도가 아니다.
2. 채택판의 기간별·사건별 세부 침수 범위. 현재 채택 수면은 기준100년 계산의 최종 저류 상태다.
3. 빙하 이동·장기 평형과 결빙-유량-침수 연동. 이동0은 설정 규칙이며 동역학 해법이 아니다.
4. 계곡 절개·식생·빙설·저류·하천 유량의 결합 계산과 지하 압력/손실수두. 현재 집수권 장부와 하도 지정 유량은 다른 규모의 계산이다.

개별 화산 위치는 별도로 미정이다. 후속40의48경계 수치 세분화 차이1% 초과도 보존한다. 사용자가 계속 해결하라고 요청하면 이 목록의 구체적인 미구현 항목을 진행하며, 표시 변경·명칭 변경을 물리 구현 완료로 보고하지 않는다. 기존 입력·해상도로 정당화할 수 없는 정밀도는 만들어내지 않는다.
