# 다음 목표: 내륙 경계 간 실제 처리 모델 연결

사용자는23,022구간의 하류 처리를 우선하라고 명시했다. 추상 합류/외력 형상 검산은 뒤로 미룬다. 후속31에서해양209경계·4,891구간의 조건부 재고/경로 전달을 구현하고 [PR #11](https://github.com/jungsb7/codex/pull/11) 병합·Pages 배포를 완료했다. 실제 해결0·미정23,022이며조건부 처리 수와 구분한다. [현재 상태](CURRENT_STATE.md), [결과](../integration/natural-world/downstream-routing/REPORT.md)를 읽는다.

1. 다음 미정 경계로 향하는 물량의 전달/수신 장부를 연결한다. 기존 경계 유입은 독립 집수권 원본 발생량이며 상류 전달을 딱 한 번 추가해야 한다. 경로 또는 격자별 누적 유량을 다시 더하지 않는다.
2. 순환과 하류 수위 결합을 먼저 차단하고 보류 경계의 수신 미배분량을 별도 보존한다. 종료된9곳과D126467/D147845/D144758은 재개하지 않는다. 부족한 자료를0으로 치환하지 않는다.
3. 집계 용량 모델을 실제 해결로 승격하지 않는다. 실제 채택에는 원본 육지 유출과 동적 수면 발생량의 전환, 저장·침투·증발의 분리, 출구 통수능·하류 조건이 필요하다. 자료가 없는 항목은null로 유지하되 코드/장부 연결을 계속 진행한다.
4. 보고는 실제 해결 수·남은 실제 미정 수·명시적 가정 아래 계산 가능한 수를 구분한다. 검사 개수를 주된 성과로 삼지 않는다. 원본지형/수계/마스크/경제/세계관과아카이브 보존.

새 사용자 요청 없이 자동 착수할 필수 작업은 아니다. 최신 사용자 요청을 우선한다.
