# 다음 목표: 더 큰 연결망으로 원본 수분 장부 확대

후속34에서 두 상류19구간을 추가해 D301678/D307820→D298591의3경계·690격자·190구간을 연결하고 [PR #14](https://github.com/jungsb7/codex/pull/14) 병합·Pages 배포를 완료했다. [현재 상태](CURRENT_STATE.md), [방법과 한계](../integration/natural-world/water-budget-chain/README.md)를 읽는다. 사용자의23,022구간 하류 처리 우선 지시를 유지한다.

1. 작은 유역을 반복하기보다 구간 수가 큰 완결 연결망을 우선 검토한다. 기존 그래프의 해양 연결 후보는D186192(57경계·2,637구간), D327739(21경계·976구간)다. 이 숫자는 후보 규모이며 계측/적용 완료 수가 아니다. 원본 집수 영역·지원되는 기후 분기·기둥/진입점을 확인해 적용 가능한 범위를 선택한다.
2. 후속34 prepare/collect/core와 후속33 surface를 재사용한다. 대상 경계마다 자기 원본 기후·눈·얕은 저장을 추출하며 D298591이나 이번 상류 값을 복사하지 않는다. 전체 원본 유출 비트·물수지·세계/기하 해시 보존을 확인한다. 북부 등 다른 산술 분기는 현재 계측/step으로 처리하지 않는다.
3. 새 연결망은 모든 상류와 해양까지의 하류를 포함해야 한다. 기존 자체 유입/손실/재고를 빼고 새 장부를 넣으며 내부 송수신과 외부 입출력을 구분한다. 원시 위상/기간 내 균등 배분/지연0 가정을 기록한다. 필요하면 별도 계측·공간 모델 입력을 먼저 확장하되 추상 합류/외력 연구로 돌아가지 않는다.
4. 조건부20,255, 원본 수분 장부 연결190, 실제 해결0·미정23,022를 구분한다.946계산 경계와235보류 경계는 현재 모형을 유지한다. 미배분은 실제 저장량이 아니다.35%얕은 저장 분배를 실제 침투율로 재명명하지 않는다.
