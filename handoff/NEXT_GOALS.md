# 후속20 종료와 다음 선택지

상태: **계절 경량화·대표12경관 점검 완료**. 이번 요청의 다음 목표는 종료됐다. 결과·측정·제약은 [후속20 보고서](../integration/natural-world/seasonal-loading/README.md)에 있다. 아래 제안은 새 사용자 요청이 있을 때만 진행한다.

## 다음 권장 목표: 대표30경관의 설명·계절 모습 초안

기존 경관 후보30곳을 기준으로 지도의 정보창에서 읽을 수 있는 짧은 설명을 정리한다. 기존 이름이 있으면 유지하고 새 설명용 이름은 임시 초안으로 명시한다. 원본 지형·기후12기간·수계 연결과 후보 식생·보류 상태를 근거로 삼는다.

- 각 장소의 이름, 원본 격자·좌표, 대표 지형, 계절 대비, 접근 가능한 지도 링크를 연결한다.
- 기존 설정 / 계산 후보 / 창작 설명 초안 / 미정 사항을 분리한다. 실제 산림·습지·강폭·침수·결빙을 확정하지 않는다.
- 국가의 정식 이름·문화·레온하르트 출신국·배신국·종교·서사 사건을 지리만으로 새 정설로 만들지 않는다.
- 전체 기간을 먼저 읽는 구현으로 되돌리지 않고 현재 지연 로딩·캐시·오류 처리와 모바일 접근성을 유지한다.
- 완료 기준은 30곳의 근거를 따라갈 수 있는 설명 초안, 지도·좌표·JSON 일치, 내용 검토와 필요한 회귀검사다.

## 별도 선택지

사용자가 물리 수계 확정을 우선하면 특정 유역1곳의 유입·저류·넘침 설정을 별도 검토할 수 있다. 전역1184곳 일괄 확정이나 종료한9곳 국지 검토의 자동 재개는 포함하지 않는다.

두 제안은 후속20의 필수 잔여 작업이 아니다. 제공 원본 전체 보관 브랜치는 계속 main과 분리한다.
