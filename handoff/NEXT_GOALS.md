# 다음 목표: 작동 후보의 공간·기후 공백 해소와 전체 적용

사용자가 승인한 진행에 따라 후속36에서 유한 토양/대수층, 침투·복귀, 출구 방류가 함께 작동하는 후보를 구현하고 PR #16 병합·Pages 실행39984782208 배포를 완료했다. [현재 상태](CURRENT_STATE.md), [후속36 방법](../integration/natural-world/finite-water-model/README.md), [검증 결과](../integration/natural-world/finite-water-model/REPORT.md)를 읽는다. 새 가정을 확정된 세계 설정으로 자동 채택하지 않는다.

1. 새 후보는57경계·2,637구간에 적용했다. 나머지20,385구간에 적용하려면 같은 원본 강수·기온/초기저장·웅덩이·진입점 입력을 일괄 준비한다. 소수 경계만 추가하는 장부 연결 반복을 목표로 삼지 않는다.
2. 가장 큰 공간 가정은 원본 문턱 위5m의 가상 수직 저장 기둥이다. 실제 주변 지형/다른 출구/침수 영역을 검사해 허용 수위 범위를 교체해야 한다. 단방향 수위 함수와 하류 진입 수위 대용값은 일반적인 역수위·역류·하도 수리가 아니다.
3. 토양/대수층은 유한하고 침투·복귀가 작동한다. 하상 침투·지역 간 지하수 교환은0가정이며 추가 설계가 필요하다. 고온 증발산·극지 눈/얼음 열수지는 여전히 원본 단순 모형의 한계다.
4. 새 모델의 적용, 가정 아래 검증, 세계 설정 채택을 따로 보고한다. 저장·침투·출구 후보가 생겼다는 진전을 설명하되,23,022구간 전체 해결이나 실제 지도 완성을 주장하지 않는다. 다음 인계도 충족한 물리 기능과 남은 구체적 공백을 기준으로 한다.

사용자는 특정 새 가정의 최종 채택 여부를 아직 정하지 않았다. 후보 구현·검증·배포는 진행 범위에 포함된다. 현실 관측값을 기다리는 과제로 바꾸지 않는다. 종료9곳/D193196/D126467/D147845/D144758, 기존108보류·14중단을 자동 해제/재개하지 않는다. 원본세계·경제·기후·지형·수계·마스크·구지도·고정아카이브 보존.

기존10.2MB 계측 게시 승인은 완료된 이력이며 후속35 배포도 성공했다. 같은 승인 질문을 반복하지 않는다.
