# 다음 작업: 남은 동적 결합과 세부 모델 검증

후속47에서 [세분 지형·경계 모델](../integration/natural-world/subgrid-boundaries/README.md)을 구현했다. 원본 평균 고도·피복 면적·웅덩이 저장량을 보존하는 구체적인 계산이며,21,308격자의 피복 경계와 모든 육지의16×16 지형·배수 경로·기간 끝 침수를 조회한다. 원본 연구를 미정이라는 말만 바꿔 처리한 작업이 아니다. 동시에 관측 검증이나 전 물리 결합 완료를 뜻하지도 않는다.

남은 작업:

1. 세분 지형을 시간 물수분 계산에 되먹이기. 이번 침수는 웅덩이 저장량을 고정한 재배치다. 새로운 지형의 저장 곡선·출구와 침투/증발/교환을 함께 적분하고, 기존 물수지와 비교해야 한다. 공간8/16분할 수위 차이1m 초과 지점과 큰 배수 연결용 채움부터 검토한다.
2. 개별 폭풍 입력과 사건별 침수·지속 시간. 기존12기간 기후와 기간 끝 재배치만으로 실제 폭풍 홍수라고 부르지 않는다.
3. 빙하 이동·장기 평형과 결빙-유량-침수 피드백. 기존 이동0 규칙은 동역학 해법이 아니다.
4. 국지 배수선의 유량·침식·퇴적, 식생/토양 입력과 생태 변화, 나머지 피복 경계. 이번 국지 트리는 면적 누적 경로이며 개별 물길 유량은null이다. 최대1,648m 연결용 채움을 실제 지형 변화로 해석하지 않는다.
5. 지하 통로 압력/손실수두와 계곡·식생·빙설·저류·개별 유량 전체 결합. 개별 화산 위치는 별도 설정이다.
