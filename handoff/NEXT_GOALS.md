## 다음 권장 목표: 명시적인 가정 단면을 받는 수리 후보의 적용성 검산

원본에 필요한 실제 단면·조도·수위가 없음을 확인했다. 같은 원본을 다시 조사해 실제값을 확정하는 대신, 설계 가정을 명시한 별도 후보 계산이 가능한지 검산한다.

1. 단면 형상·하폭·둑 높이·조도·유량·하류 경계 수위를 필수 입력으로 하는 별도 계약을 만든다. 원본29.055km골짜기 폭과0.05m하강 규칙을 수리 입력으로 자동 채택하지 않는다. 미입력은null·계산불가이며 사용자가 실제 자료로 제공하지 않은 값은 모두 설계 가정으로 표시한다.
2. 단일 도달구간의 단순 정상류·역수위 후보를 해석 가능한 균일 수로 사례와 독립 검산한다. 에너지/마찰 경사·수심·한계류·역류 및 계산 중단 조건을 구별한다. 적용 범위를 벗어나면 결과를 확정하지 않는다.
3. 검산을 통과한 경우에만 D298591 경로의 첫 완만한 구간에 폭·조도·하류 수위 가정의 민감도를 별도 표시한다. 원본12위상 기본 유량을 동시100년 수문곡선으로 취급하지 않으며 기존 조건부 방류와 자동 합산하지 않는다. 전체1473km동적 결합/실제 침수는 별도 범위다.
4. 후보가 있어도 실제수위·방류null,자동채택false,108하류수위 보류·14우회 중단과 상류 적설/열수지 공백을 유지한다. 실제 소하천·피복·눈 두께·결빙을 해결했다고 표시하지 않는다.

새 사용자 요청 없이 자동 착수할 필수 작업이 아니다. 다른1,183경계로 일반화하지 않고 종료된9곳 검토 및 D126467/D147845/D144758보류를 재개하지 않는다. 전체 아카이브는 main과 분리한다.
