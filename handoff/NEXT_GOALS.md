# 다음 목표: 계산 연결을 넘어 침투·저장·출구 모델 완성

사용자가 ‘도대체 언제 해결되나’, ‘가정이 없어서 대부분 미정인가’를 물었다. 기존 지형/기후/수계와 계산 가정은 있지만, 일부 물리 모델/입력과 세계 설정 채택이 남았다고 설명했다. 사용자는 특정 새 가정의 채택을 아직 결정하지 않았다. [현재 상태](CURRENT_STATE.md), [완료 기준](../integration/natural-world/basin-water-budget/COMPLETION.md)를 읽는다.

1. 후속35는57경계·2,637구간 추가, 합계60경계·2,827구간 원본 장부 연결을 구현·검증하고 [PR #15](https://github.com/jungsb7/codex/pull/15) 병합·Pages 배포를 완료했다. 사용자는10.2MB 원본 계측 자료의 게시를 명시 승인했다. 이전 게시 차단은 해소됐으며 같은 승인 질문을 반복하지 않는다.
2. 작업 목표를 작은 유역의 연결 숫자 증가에서 **침투·유한 저장·출구/하류 처리의 작동 모델**로 바꾼다. 원본 값/새 설계 가정/계산 결과/채택 상태를 분리한 후보를 구체화한다.35%분배를 실제 침투로 바꾸거나 임의 값으로 null만 없애지 않는다.
3. 전체23,022구간을 대상으로 저장·침투/복귀·증발·넘침/해양·명시적 폐쇄가 결정되고, 고온·극지·수위 결합 예외와 전역 보존/시간 간격 안정성을 검증하는 완료 기준을 따른다. 새 가정이 허용되면 창작 세계 모델로 설계·검증할 수 있으며, 새 가정 금지라면 원본에 없는 실제값은 계속 미정이다. 현실 관측자료만 기다리는 과제로 만들지 않는다.
4. 현재 지표는 원본 수분 장부2,827 / 집계만17,428 / 자체보류2,767이다. 실제 물리 채택 완료0과 혼동하지 않는다. 기준 없는 완료 날짜나 남은 ‘다음’ 횟수를 약속하지 않는다. 검사 수가 아니라 충족한 완료 조건과 남은 공백을 보고한다.

기존 core/surface/계측과 큰 유역 입력을 재사용한다. 기존108보류·14중단, 종료9곳 및D126467/D147845/D144758 내부 물리계산은 사용자 지시 없이 해제/재개하지 않는다. 원본세계·경제·기후·지형·수계·마스크·구지도·고정아카이브를 보존하며 최신 사용자 요청을 우선한다.
