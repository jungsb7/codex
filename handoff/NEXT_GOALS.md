# 다음 작업: 빙설·동토와 수문 장부 연결

후속50 내부 저류칸의 구현·검증을 마쳤다. [방법](../integration/natural-world/internal-pond-model/README.md),[결과](../integration/natural-world/internal-pond-model/REPORT.md),[배포](../integration/natural-world/internal-pond-model/validation/deployment.json)를 읽는다. 최종 GitHub/Pages 확인 뒤 같은 작업에서 다음 기존 범위를 계속 진행한다.

1. [유한한 완료 기준](MODEL_COMPLETION_CRITERIA.md)의51단계부터 진행한다. 기존 눈 저장·기온·강수,명시한 얼음 유동/융해·결빙/동토 억제 법칙을 같은 물 장부에 연결한다. 먼저 입력 범위·초기 상태·계수·반복 기간을 고정한다. 질량 보존/비음수/이동0 대조/시간 비교/연간 재고 변화율로 판단하며 실제 빙하 평형 검증으로 포장하지 않는다.
2. 이어52개별 물길 유량·침식/퇴적,53피복 경계·생태,54이미 지정된 통로3곳의 압력/손실수두와 전체 결합을 순차 진행한다. 새 지하 연결·화산 위치·관측 자료 확보를 새 필수 범위로 추가하지 않는다.
3. 후속50의 시간4.046m·공간14.574m 민감도와 가정한 내부 문턱의 큰 저류 효과를 후속 입력의 한계로 유지한다. 모든 지점 수렴이나 모든 세부 구현 완료로 상태를 변경하지 않는다. 칸 내부2차원 흐름은 이번 구현이 아니다.

후속50의32분할·240단계 결과와101년 말 원본 격자별 눈/토양/지하수/이동 저장·내부 수량을 공개manifest.finalState로 제공한다. 이전 원본·정설v1를 덮어쓰지 않는다. 국지 새 사례를 임의로 늘려 완료 기준을 계속 확장하지 않는다.

전체 수문 계산은 하나씩 실행한다.16GiB에서 시작 시 여유가 있어도 동시 실행 중 메모리 한도를 넘을 수 있다. 원본·경제·구지도·아카이브·Oracle·이전 수치 보존. 옛 빌드/패키징 스크립트 금지. 공개 GitHub/Pages 승인 유효,동일 승인 재질문 금지. 공개 사이트 네트워크 제한은 우회하지 않는다.
