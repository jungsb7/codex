# 후속22 완료 범위와 다음 선택지

대표30경관의 두 공전 위상 나란히 비교를 구현·검증하고 [PR #2](https://github.com/jungsb7/codex/pull/2) 병합·Pages 배포까지 완료했다. A/B 선택·교환·기온/강수/후보유량 차이·공유 주소·지도 연결·비교 JSON을 제공한다. [사용·검증](../integration/natural-world/landscape-compare/README.md), [현재 반영 상태](CURRENT_STATE.md)를 확인한다. 아래는 새 사용자 요청이 있을 때만 진행할 별도 제안이다.

## 다음 권장 목표: 대표 경관 찾기 개선

30곳을 하나의 선택 목록에서 탐색하는 대신 기존 권역·숲/초원/습지 분류·표제 검색으로 좁혀 원하는 경관과 비교 화면을 빨리 찾도록 개선할 수 있다.

- 기존30대표점과 원본 catalog를 그대로 사용한다. 새 경관·고유 지명·세계관 설정을 생성하지 않는다.
- 검색·분류·결과 없음·선택 유지·키보드·모바일 사용을 검증한다.
- 필터 변경으로 전 대륙 계절 배열을 선로딩하지 않는다.
- 비교 자료는 대표 한 격자의 표본이며 실제 피복·침수·결빙 채택으로 확대하지 않는다.

## 별도 선택지

사용자가 특정 경관의 설정 채택이나 특정 유역의 물수지 검토를 원하면 대상과 확정 범위를 구별해 진행한다. 전역1184미정 경계의 일괄 확정과 종료한9곳 국지 검토 자동 재개는 포함하지 않는다.

이는 후속22의 필수 잔여 작업이 아니다. 전체 원본 보관 브랜치는 main과 분리해 유지한다.
