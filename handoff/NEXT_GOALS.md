# 다음 목표: 원본 수분 장부 연결을 다른 경계로 확장

사용자의23,022구간 하류 처리 우선 지시를 유지한다. 후속33에서 D298591의619격자·171구간에 원본 강수·눈·혼합 얕은 저장·육지/수면 증발과 상류2경계 수신을 연결하고 [PR #13](https://github.com/jungsb7/codex/pull/13) 병합·Pages 배포를 완료했다. [현재 상태](CURRENT_STATE.md), [방법과 한계](../integration/natural-world/water-budget-link/README.md)를 먼저 읽는다.

1. 다른 대상 경계의 원본 기후/저장 계측, 집수 영역, 물리 진입점과 용량 자료를 확보한다. 후속24의 원본 계측/step 및 후속33의 교체 방식을 재사용한다. D298591의 기후·저장·출구 값을 다른 경계에 복사하지 않는다.
2. 원본 자체 발생·상류 수신·강수와 내부 얕은 저장 이동을 구분하고, 기존 집계 장부를 제거한 뒤 새 지역 장부를 연결한다. 수면 전환 후 육지 유출/증발산과 수면 강수를 중복 적용하지 않는다. 위상 평균과 원시 위상의 시간 대응 가정을 기록한다.
3. 실제 침투/열수지/적설두께/결빙/출구 통수능/역수위는 필요한 입력과 채택 근거가 없으면 null이다. 원본35%분배를 실제 침투율로 재명명하지 않는다. 매년 약6.008km³ 눈 누적과 후속26의108보류·14중단을 해제하지 않는다.
4. 조건부20,255구간, 원본 수분 장부 연결171구간, 실제 해결0·미정23,022를 구분한다. 다른948계산 경계와235보류 경계는 현재 모형을 유지한다. 보류 미배분량은 실제 저장량이 아니며 자동 방류하지 않는다.

외력 형상/추상 합류 검산으로 자동 복귀하지 않는다. 종료9곳 및D126467/D147845/D144758 내부 물리계산을 재개하지 않는다. 원본세계/경제/지형/기후/수계/마스크/구지도/별도아카이브를 보존한다. 새 사용자 요청 없이 자동 착수할 필수 작업은 아니며 최신 요청을 우선한다.
